> 问题：此前所有研究都用日线，真正的分钟级日内策略（开盘区间突破、尾盘动量、VWAP 回归、噪声带趋势）从没检验过。

> `research_ledger_t_grid.md`）。这里用 Alpaca 免费的 SIP 分钟线（2016 年起），在 1 万美元 IBKR Pro Tiered 账户的真实约束下

  作为背景行（CTX_none）照报，不计试验。

### 0.3 执行与成本

- 每天是一个独立的分钟序列，bar i = 09:30 + i 分钟。**规则只用已经走完的分钟线**：在 bar i 收盘时决策，在 bar i+1 的开盘价成交。
  两个例外是事先就知道的挂单：(1) **止损单**挂在固定价位，某根分钟线的最低（空头：最高）碰到止损价就成交，成交价 = 止损价，
  若该分钟开盘已越过止损价则按开盘价；(2) **"收盘平仓"**按当天最后一根常规时段分钟线的收盘价（作为收盘集合竞价 MOC 的近似；
  它与官方收盘价的差见 0.2）。组合包装里早上卖出隔夜仓位按 09:30 分钟线开盘价（开盘集合竞价 MOO 的近似）。
- **滑点**：每股 max(1 美分, 1 bp × 价格)，买入加、卖出减（止损单同样）；敏感性 2 倍、3 倍。
- **佣金和费用**：每单 `quant.backtest.costs.ibkr_order_cost`（IBKR Pro Tiered：每股 0.0035 美元、每单最低 0.35、最多 1%，加交易所 /
  清算费、转嫁费，卖出加 SEC 费和 FINRA TAF；半价差参数设 0，因为滑点已单独计）。
- **整股、1 万美元起步**：每笔用当时可用现金（留 2 美元付佣金）能买的最大整股数，1 倍敞口，不加杠杆（文献里 ORB / 噪声带用了
  2–4 倍杠杆或波动率目标仓位，这里不用）。空头同样 1 倍。日内做空不收借券费（不过夜）。
- **包装（每条规则两种，都计试验）**：
  - **单独（standalone）**：只在日内持仓，隔夜空仓；现金按 T-bill 日利率计息（敏感性：零利息——IBKR 对小账户的现金利息条件
    需主人核实）。
  - **组合（combo）**：每天收盘买入 QQQ 持有过夜（MOC），次日开盘卖出（MOO），日内按规则操作。规则在收盘时仍持有的多头直接留作
    隔夜仓位（不卖了再买），并在收盘把现金补买成整股。这样与 ONEQ 买入持有比较才公平（大部分时间都在市场里）。
- **账户（每个配置三种，只有"保证金账户"参与判定，另两种是 1 万美元可行性）**：
  - **保证金账户（主判定）**：不受 PDT 限制（相当于权益 ≥ 2.5 万美元），可做空。
  - **保证金账户 + PDT**：权益（前一日收盘）低于 2.5 万美元时，任意连续 5 个交易日内最多 3 次日内交易（同一天开仓又平仓算一次）。
    事前规则：如果这一笔"有可能"成为日内交易（单独包装：每一笔都是；组合包装：空头、或者有止损 / 信号 / 时间退出的多头）且窗口内
    已用满 3 次，就跳过这一笔。另报 PDT 实际卡住的天数。事实：FINRA 已提议修改 PDT 规则（以日内保证金要求取代 2.5 万美元门槛），
    是否已生效、IBKR 何时执行，主人须自行核实。
  - **现金账户**：不能做空（空头腿全部跳过）；只能用已交割现金：卖出款 T+2（2024-05-28 起 T+1）个交易日后交割。日内买入只能用当天
    已交割的现金（否则当天卖出会构成"良好信用违规"GFV）；组合包装收盘买入的隔夜仓位次日开盘卖出，所以可以用到次日才交割的现金。
- 起点：2016-01-04 是预热日（组合包装在这天收盘买入第一笔隔夜仓位）；收益从 **2016-01-05** 起算。ONEQ、QQQ 基准在 2016-01-04 收盘
  买入，扣 `etf_order_cost`（半价差 ONEQ 2 bp、QQQ 1 bp）。

### 0.4 规则（10 条 × 2 种包装 = 20 次试验）

记号：O_i、H_i、L_i、C_i = bar i 的开、高、低、收（调整价）；n = 当天分钟数（390，半天市 210）；P_prev = 前一交易日最后一根分钟线收盘；
VWAP_i = Σ_{j≤i} vw_j·v_j / Σ v_j（vw 是 Alpaca 给的分钟成交均价）；sd_i = 成交量加权的价格偏离 VWAP 的标准差
√(Σ v_j·vw_j² / Σ v_j − VWAP_i²)。

| 编号 | 规则 | 细节 |
|---|---|---|
| M1a | 30 分钟开盘区间突破（ORB），只做多 | 区间 = bar 0–29 的最高 RH / 最低 RL；从 bar 30 起第一根收盘 > RH 的分钟 → 下一分钟开盘买入；止损 RL；收盘平仓。每天最多 1 笔，最后决策 bar n−3 |
| M1b | 同上，多空 | 第一次收盘 > RH 做多（止损 RL）或收盘 < RL 做空（止损 RH） |
| M1c | 5 分钟 ORB（Zarattini & Aziz 2023） | bar 4 收盘 > bar 0 开盘 → bar 5 开盘做多，止损 = bar 0–4 最低；反之做空，止损 = 最高；相等不交易；收盘平仓（不用文献的 10R 止盈） |
| M2a | 尾盘动量，多 / 空仓（Baltussen 等 2021 的口径） | C_{n−31}（15:29 分钟线，15:30 走完）/ P_prev − 1 > 0 → bar n−30 开盘买入，收盘平仓；否则空仓 |
| M2b | 同上，多空 | < 0 时做空 |
| M2c | 尾盘动量，用第一个半小时（Gao, Han, Li & Zhou 2018） | 信号 = C_29（10:00）/ P_prev − 1 的正负，多空，持有最后 30 分钟 |
| M3a | VWAP 回归，多空 | 决策 bar 30 至 n−61（10:00 起、最后一小时不再开仓）：C_i < VWAP_i − 2·sd_i → 下一分钟做多；> VWAP_i + 2·sd_i → 做空。平仓：收盘回到 / 穿过 VWAP 后的下一分钟开盘，或持有满 60 分钟后的下一分钟开盘，或收盘。平仓后可再开 |
| M3b | 同上，只做多 | |
| M4 | 噪声带趋势（Zarattini, Aziz & Barbon 2024 "Beat the Market"，原文用 SPY） | σ_i = 前 14 个交易日 \|C_i / O_0 − 1\| 的平均（对应同一分钟 i；半天市缺的分钟不计）；上沿 UB_i = max(O_0, P_prev)·(1+σ_i)，下沿 LB_i = min(O_0, P_prev)·(1−σ_i)。只在整点 / 半点走完的分钟（10:00 … 15:30）检查：空仓时 C > UB 做多、C < LB 做空；多头在 C < max(UB, VWAP) 时平仓、空头在 C > min(LB, VWAP) 时平仓（可同时反手）；下一分钟开盘成交；收盘平仓。1 倍仓位（不用原文的波动率目标和最高 4 倍杠杆） |
| M5 | M1a + 趋势过滤 | 只在 QQQ 前一交易日收盘（Yahoo 复权价）高于其 200 日均线的日子做 M1a |

只作背景（不计试验、不判定）：CTX_open_to_close（每天开盘买、收盘卖）；CTX_none（不做日内交易；组合包装 = 只持隔夜 = 日历研究 C4）。
只作参考（不判定）：同样 10 条规则用在 SPY、TQQQ 上（单独包装、保证金账户，报毛收益和每笔平均）；TQQQ 没有价格还原，1 美分滑点
在早年被高估。

### 0.5 区间（两折，事先指定）

- 评估：2016-01-05 至 2026-09-30。**第一折 H1：2016-01-05 – 2020-12-31；第二折 H2：2021-01-01 – 2026-09-30。**
- M4 的 σ 需要前 14 个交易日，2016-01 前三周不交易（照记）。

### 0.6 通过标准（扣成本后，保证金账户、1 倍滑点；`quant.evaluation.criteria.ab_verdict`，三段 = 全区间、H1、H2）

- A（收益更高）：三段 CAGR 都高于 ONEQ 买入持有，且全区间月度超额（规则 − ONEQ）t ≥ 2；
- B（更稳且不太贵）：三段最大回撤都比 ONEQ 浅至少 10 个百分点，且 CAGR 落后 ONEQ 不超过 3 个百分点。
- A 或 B = "通过"。**Bonferroni 版**：A 的 t 门槛换成 20 次试验的单侧 5% 门槛 **2.81**（`bonferroni_t(20)`）；两种结论都报。
- **1 万美元可行**另需：同一配置在"保证金 + PDT"或"现金账户"下也通过，并且 2 倍滑点下仍通过。
- 每个配置另报：每年交易笔数、胜率、每笔平均收益（成本前 / 后，bp）、在场时间占比、最大回撤、按年收益、成本拖累（毛 CAGR − 净 CAGR、
  以及成本 + 滑点美元 / 平均权益 / 年）、PDT 跳过笔数和卡住天数、现金账户跳过笔数。

### 关键发现

1. **成本前确实有一点东西，但每笔只有几个 bp。** 成本前每笔平均：M4 +6.0 bp、M1a / M1c / 开盘买收盘卖约 +3 bp，其余 ±1 bp 左右或为负。
   1 万美元账户每笔来回的成本约 3 bp（1 美分或 1 bp 滑点 × 2 + 每单最低 0.35 美元佣金 × 2），几乎把这点优势全吃掉：单独包装的
   成本拖累每年 4–18 个百分点（毛 CAGR − 净 CAGR），组合包装每年 8–30 个百分点（每天额外的开盘卖 / 收盘买两单）。
2. **只有 M4（噪声带）扣成本后仍为正、回撤很浅**（单独 8.7% / −10.3%，2× 滑点 4.1%，3× 滑点 −0.4%），但离 ONEQ 的 18.3% 很远；
   它在 2018、2022 年跑赢（34.8%、13.5%），牛市年份大幅落后。组合版 13.2% 仍落后 ONEQ 5 个百分点。
3. **VWAP 回归（M3）是最差的**：成本前就是负的，每年 230–470 笔，扣成本后单独版 −6.5% 至 −16.8% / 年，回撤 −54% 至 −86%。
4. **尾盘动量（M2）在 2016–2026 的 QQQ 上基本消失**：成本前每笔 +0.2 至 +1.1 bp（不显著），扣成本为负；Gao 等的"前半小时"信号
   第二折为负。
5. **组合包装不划算**：每天收盘买、开盘卖 QQQ 的成本（每年约 7 个百分点）远高于它想补回来的隔夜收益；"只持隔夜"本身（= C4）
   扣成本后只有 4.7%。比起"日内规则 + 隔夜持有"，直接买入持有 QQQ（20.4%）好得多。
6. **1 万美元账户的现实约束会让情况更糟**：
   - PDT（保证金账户、权益 < 2.5 万）：单独包装几乎每天都是日内交易，每 5 天只能做 3 次，约 40% 的交易被挡掉
     （M1b / M1c / M2b / M2c / 开盘买收盘卖各约 1,050 笔，M3a 3,431 笔）；M4 PDT 版 5.6%（单独）/ 8.1%（组合）。
   - 现金账户：不能做空（多空规则的空头腿全部跳过）；2024-05-28 以前 T+2 交割，每天全仓来回只能隔一天做一次；组合包装在 T+2 时期
     807 天买不回隔夜仓位。现金账户版没有一个超过 3.7%。

### 没有检验 / 局限

- 只用了文献默认参数，没有调参（这是事先登记的约束）；没有用文献里的杠杆（2–4 倍）或波动率目标仓位——在 1 万美元账户上，
  加杠杆会同比放大成本前的几个 bp，也同比放大成本和回撤，且 PDT 限制不变。
- 没有挂限价单、没有用盘前 / 盘后数据、没有逐笔（tick）或报价（NBBO）数据：滑点是假设值（max(1 美分, 1 bp)），没有用真实买卖价差；
  "收盘成交"用 15:59 分钟线收盘近似收盘竞价（与官方收盘中位差 1 bp）。
- 个别坏价（分钟最高 / 最低价偶尔差 1%）会影响突破和止损，没有清洗。
- 只做了 QQQ（判定）和 SPY / TQQQ（参考，不判定）；没有做个股的日内策略（Alpaca 有数据，但不在本次登记范围）。
- IBKR 现金利息（小账户的利息条件）、PDT 规则的修改进度（FINRA 已提议改为日内保证金要求），主人需自行核实；结论对这两点不敏感：
  即使没有 PDT 限制，也没有配置通过。
