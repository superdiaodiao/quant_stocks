## 0. 事先登记（2026-10-14，在计算任何规则结果之前写下；写下时已经取完数据并做完数据核对，见 0.2）

### 0.1 先说清楚：比特币的历史很短，而且被几次大牛市主导

- 可靠的日线从 2011 年起（Bitstamp），两家以上独立来源重叠从 2014-09 起；评估区间只有约 12 年，其中 2015–2017、
  2020–2021、2023–2024 三轮牛市贡献了绝大部分涨幅，中间是 −70% 至 −85% 的回撤。任何结论都只是"这段已知历史上的表现"，
  **没有样本外**：作者在写本登记前就知道比特币 2014–2026 的大致走势（这是公开常识）。
- 本仓库此前没有做过比特币研究；200 日均线、动量、波动率目标这几类规则在 QQQ 上都试过（`research_ledger_qqq_timing.md`、
  `research_ledger_regime.md`、`research_ledger_voltarget.md`），均未在 QQQ 上通过；这里是同类教科书规则换一个资产。
- 约束：参数全部是教科书默认值（200/50 日均线、3/12 个月动量、40% 目标波动、5/10/20% 袖子、5/25 再平衡带），不做参数搜索；
  12 个配置 + 1 个诊断一次跑完，不论好坏都照记，不调参重试。

  2014-09-17 之前只有 Bitstamp 一个来源，只用于信号预热（12 个月动量最早要 2013-09 的价格）和只报告的长区间背景。
- **数据核对（写本节前已做，不是规则结果）**：日收益相差 ≤ 0.5 个百分点的天数占比：Bitstamp–Coinbase 93.6%

  Kraken 与其余三家 99.6%–100%；最大单日差 6.5 个百分点（2015-08-19，Bitstamp–Yahoo）。不一致集中在 2014–2018 年

### 0.3 执行与成本

- 信号只用决策行 t 收盘及以前的数据；**下一行收盘**成交（新权重从 t+2 的收益起算）。单独 BTC 规则在 7 天 UTC 日历上
  运行（决策、成交都可以在周末）；袖子组合在美股交易日上运行（BTC 在 UTC 日 S 的收盘成交）。
  事实（见 0.8）：IBKR "Crypto Basic" 权限只能在美东周日 3:00 至周五 16:00 交易，周末成交需要 "Crypto Plus"（7×24）。
- 1 万美元现金起步；入场收盘日 **2014-09-30**（美股交易日，也是 UTC 日），目标在 2014-09-29 决定。所有基准同日买入、同样扣成本。
- **BTC 成本（IBKR 现货加密，经 Paxos / Zero Hash）**：佣金 0.18% × 成交额（月成交额 ≤ 10 万美元档），每单最低 1.75 美元、
  但不超过成交额的 1%；另加半价差 **5 bp**；Paxos 每月 0.15 美元账户费（所有含 BTC 腿的配置，含 BTC 买入持有，从第一个月起每月扣）。
  2024 年以前市场上没有现货 ETF，全区间都按这个现货成本建模。
- QQQ：`etf_order_cost`（每股 0.0035 美元、最低 0.35、最高 1% + 每股 0.0005 + 卖出 0.3 bp + 半价差 1 bp）。现金腿不收费，
  按 T-bill 日利率计息（单独 BTC 规则：只在美股交易日计息，总额不变）。每腿调整 ≤ 1 美元不下单。
- 只报告的敏感性（不判定、不算试验）：不计成本；BTC 半价差 25 bp；现金零利息；数据换成 Coinbase（2015-07-20 前用 Bitstamp）
  和 Yahoo（2014-09-17 前用 Bitstamp）；袖子组合 2024-01-12 起 BTC 腿换成 IBIT（股票成本、半价差 2 bp，IBIT 收益已扣 0.25% 费率）。

### 0.4 规则（12 个配置）

记号（全部 7 天 UTC 日历，Bitstamp 主序列）：P_t = UTC 日 t 收盘；SMA_n = 最近 n 个日历日收盘的平均（含 t）；
σ30_t = 最近 30 个日收益的标准差 × √365；月末 = 每个 UTC 日历月的最后一天。

| 编号 | 规则 | 决策 / 调仓 |
|---|---|---|
| BT1a | 趋势：P_t > SMA200_t 持有 BTC，否则现金 | 每日决策，状态变化时成交 |
| BT1b | 变体：SMA50_t > SMA200_t 持有 BTC，否则现金 | 同上 |
| BT2a | 时间序列动量：月末 P / 3 个月前月末 P − 1 > 0 持有 BTC，否则现金 | 月末决策，下一日收盘成交 |
| BT2b | 变体：12 个月 | 同上 |
| BT3 | 波动率目标：BTC 权重 = min(1, 40% / σ30_t)，其余现金 | 每日决策；新目标与上次成交目标相差 > 10 个点才成交 |
| BT4a / b / c | QQQ + BTC 固定袖子 5% / 10% / 20%（其余 QQQ） | 每月最后一个美股交易日决策，下一交易日收盘再平衡 |
| BT4d | 90% QQQ + 10% BTC，"5/25 带"（Swedroe）：BTC 实际权重偏离 10% 超过 min(5 点, 10% × 25%) = 2.5 点（即离开 7.5%–12.5%）时再平衡 | 每个交易日检查，下一交易日收盘成交 |
| BT5a / b / c | BT4a / b / c，BTC 部分加 BT1a 趋势过滤（UTC 日 S 的 BT1a 状态；"关"时这部分放现金） | 月末再平衡 + 状态变化时成交 |

外加 **BT6（只作诊断）**：UTC 周六、周日的 BTC 日收益均值与周一至周五的均值之差（Welch t），以及周末占全部对数收益的比例；
全区间和两折各报一次。它不是可交易策略，但计入试验次数。

**试验次数：13**（12 个配置 + BT6）。单侧 5% Bonferroni t 门槛 = **2.67**（`bonferroni_t(13)`，正态）。

### 0.5 区间（两折，事先指定日期，不用按天数对半）

### 0.6 通过标准（扣成本后，与其它台账相同；`quant.evaluation.criteria.ab_verdict`，三段 = 全区间、H1、H2）

- **相对 ONEQ 买入持有（主判定，所有配置）**：
  - A（收益更高）：三段 CAGR 都高于 ONEQ，且全区间月度超额（规则 − ONEQ）t ≥ 2；
  - B（更稳且不太贵）：三段最大回撤都比 ONEQ 浅至少 10 个百分点，且 CAGR 落后 ONEQ 不超过 3 个百分点。
  - A 或 B 满足其一 = "通过"。**Bonferroni 版**：A 的 t 门槛换成 2.67（B 不是显著性检验，不变）；两种结论都报。
- **单独 BTC 规则（BT1–BT3）另对 BTC 买入持有判定**（同样的 A / B，基准换成 BTC 买入持有）：择时是否比"一直拿着"好。
- **袖子组合（BT4–BT5）另对 QQQ 买入持有判定**（同样的 A / B，基准换成 QQQ）：加了 BTC 是否比纯 QQQ 好。
  另报"回撤可接受"标记：两折的最大回撤都不比 QQQ 深 5 个百分点以上。另报 BTC 腿的风险贡献
  （平均持有权重 × cov(BTC, 组合) / var(组合)，按交易日收益，全区间和两折）。
- 每个配置另报：波动、夏普、卡玛、最差年份、交易次数、成本（美元和每年拖累）、平均 BTC 敞口、敏感性（0.3）。

### 0.8 IBKR 实现事实（登记时查到的，来源见结果节）

- 佣金：0.18%（月成交额 ≤ 10 万美元）/ 0.15% / 0.12%，每单最低 1.75 美元但不超过成交额 1%，不另加价差或托管费；
  Paxos 每月 0.15 美元账户费（IBKR 加密佣金页，2026-10-14 读取）。
- 加密资产在 Paxos / Zero Hash 以客户名义托管，不在 IBKR，不受 SIPC 保护；只对符合条件的 IBKR LLC（美国）等客户开放，
  需单独开通加密交易权限（Crypto Basic / Crypto Plus）。
- 保证金 / 做空：未在 IBKR 美国页面上找到明确条文；IBKR 香港的说明写明加密持仓不可用保证金、不支持做空；Crypto Plus 要求先把资金
  转进 Paxos 账户（即全额现金买入）。本研究只做多、不加杠杆，结论不依赖这一点。
- 现货 ETF：IBIT、FBTC 费率都是 0.25%/年，按普通股票佣金交易，可放在普通（含保证金）账户里。

### 诚实的解读

- BTC 2014–2026 的结果被少数几年主导：BT4b 对 QQQ 的超额里 2017 年一年就是 +46 点，2020 年 +19 点；2015–2025 年 BT4b 几何平均 25.1%，
  去掉 2017 年 20.8%，再去掉 2020 年 16.4%（QQQ 同口径 18.5% / 17.2% / 14.1%）。BTC 本身 66.5% → 33.7% → 18.2%。
  也就是说，"加 BTC 有用"的结论有很大一部分押在"未来还会有 2017 年那样的年份"上，这在统计上没法从 12 年、两三轮周期里确认。
- 相关性在变：2019 年以前 BTC 与 QQQ 几乎不相关，现在 0.4–0.6。早年的分散效果不能直接外推。
- 最近两年（2025、2026 年 1–9 月）BTC 跑输 QQQ，所有袖子组合这两年都落后 QQQ（BT4b −2.6 / −2.1 点）；BTC 截至 2026-09-30 仍在 −53% 的回撤里。
- 没有样本外：作者知道这段历史；BTC 的长期回报来源（采用扩散、减半叙事、ETF 资金流）都不是规则能捕捉的东西。
  结论只能写成"在 2014–2026 已知历史上，教科书规则 / 小比例 BTC 袖子扣成本后的表现如此"，不能写成"以后会跑赢"。

## 结论

- 数据可靠：四个免费来源 2019 年起几乎逐日一致，早年差异真实但不改变任何判定。
- 单独持有 BTC 或对 BTC 择时：形式上大幅跑赢 ONEQ，但回撤 −64% 至 −83%；**择时没有比一直持有更好**，不推荐作为"跑赢纳指"的主策略。
- QQQ + 小比例 BTC：在已知历史上扣成本后对 ONEQ 显著（过 Bonferroni），对 QQQ 也领先，但对 QQQ 的显著性**不过** 13 次试验的 Bonferroni 门槛，
  且主要来自 2017、2020 两年；加趋势过滤的版本回撤不比 QQQ 深。是否采用属于风险偏好判断，本台账不据此冻结任何策略进前瞻观察。
