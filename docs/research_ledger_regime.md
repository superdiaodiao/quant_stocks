# 按市场状态切换持仓（regime switching，长仓 ETF）：研究台账

> 思路：不做"进 / 出"择时，而是按事先定好的教科书规则，根据市场状态决定**持有什么**（股票 ETF、债券 ETF、低波 ETF、黄金）。
> 代码 `scripts/research_regime.py`，测试 `tests/test_research_regime.py`，结果 `output/research_only/regime/`。
> 加载、成本、日期保护复用 `scripts/research_qqq_timing.py`（`parse_chart`、`load_kf_rf`、`fill_rf`、`order_cost`、`assert_dev_dates` 等）。

## 0. 事先登记（2026-10-05，下载数据和计算任何结果之前写下）

### 0.1 必须先说清楚的一点：这些年份不是"没见过的"

- QQQ 200 日均线进出择时（`T01_L200_b2`）在 2015-01 至 2026-09 的一次性检验**未通过**（年化落后 QQQ 4.6 个点，见 `docs/research_ledger_qqq_timing.md`）；
  道氏理论、唐奇安通道（对 ONEQ）也都未通过（`docs/audit_timing_studies.md`）。
- 本项研究用的是 2003–2026 的全部可得 ETF 历史，其中 2015–2026 已经被前几项研究反复看过，1999–2014 的 QQQ 也在开发期看过。
  因此这里**没有样本外**：即使某条规则"通过"，也只能算"教科书规则在已知历史上的表现"，证据强度远低于真正的一次性检验。
- 能做的约束：规则全部用教科书 / 业界最常见的默认参数，不做任何参数搜索；每条规则最多一个事先写下的变体；全部试验都计数；结果不论好坏都照记。

### 0.2 数据

- Yahoo chart API 复权收盘价（adjclose，含分红再投资），2026-10-05 下载，只放本机 `research_cache/regime/raw/`，不进 Git：
  QQQ、ONEQ、SPY、IEF（7–10 年美国国债）、TLT、SHY、BIL、GLD、MTUM、USMV、QUAL、VLUE。
  （QUAL、VLUE、TLT、SHY、BIL 只做数据核对 / 参照，不进任何规则。）
- 截止日：最近一个完整月末 **2026-09-30**；读数时立即截断并断言没有更晚的行（复用 `truncate_dev` / `assert_dev_dates`，截止日改为 2026-09-30）。
- 短期国债收益（只用于 R2 的"T-bill 12 个月收益"）：Ken French 日度 RF（到 2026-08-31），之后用 FRED DTB3 ÷ 252 补，与 QQQ 台账相同。
- 核对：每只 ETF 复权价日收益 vs "收盘价 + 分红"重算；交易日对齐（缺失天数）；BIL 12 个月收益 vs KF RF 12 个月收益；QQQ 与上一项研究缓存文件的一致性。

### 0.3 执行与成本（所有规则相同）

- 信号只用决策日 t 收盘及以前的数据；**t 的下一个交易日收盘**成交（新权重从 t+2 的日收益开始算）。
- 起点：每条规则在其"入场收盘日" S 建仓（用 S 前一交易日的信号），基准 ONEQ、参照 QQQ 也在 S 收盘买入，同样扣成本。
- 每一单：IBKR Tiered（每股 0.0035 美元，最低 0.35，最高成交额 1%）+ 每股 0.0005 美元 + 卖出 0.3 bp + 半价差
  （QQQ、SPY、IEF、GLD 1 bp；ONEQ、MTUM、USMV 2 bp），股数用当日复权前收盘价（Yahoo 的 close，已拆股调整）。账户 1 万美元起。
- 只有当"目标权重"改变时才交易（R5 每月变一次）；两次调仓之间权重随行情漂移，不做日内再平衡。
- 敏感性（只报告、不判定、不算新试验）：t 当日收盘成交。

### 0.4 规则（每条一个教科书设定，最多一个变体）

记号：P(X) = X 的复权收盘价；SMA200 = 最近 200 个交易日（含当日）的简单均线；月末 = 每月最后一个交易日。

| 编号 | 规则 | 变体 |
|---|---|---|
| R1 趋势状态 | 每日：P(QQQ) > SMA200(QQQ) → 100% QQQ；否则 → 100% IEF（无带宽） | R1b：否则 → 100% USMV |
| R2 双动量（Antonacci 绝对动量） | 月末：QQQ 过去 12 个月（252 个交易日）总收益 > 同期 T-bill 累计收益 → 下月 100% QQQ；否则 → 100% IEF | R2b：先比 QQQ 与 SPY 的 12 个月收益取较强者（相对动量），较强者的 12 个月收益 > T-bill → 持有它，否则 IEF |
| R3 波动状态 | 每日：QQQ 过去 20 个交易日日收益的年化标准差 < 它自己过去 252 个交易日（含当日）的中位数 → 100% QQQ；否则 → 100% USMV | R3b：否则 → 50% QQQ + 50% IEF（进入该状态时按 50/50 买入，状态不变不再平衡） |
| R4 因子轮动 | 每日：P(SPY) > SMA200(SPY)（"大盘上升趋势"）→ 100% MTUM；否则 → 100% USMV | 无 |
| R5 简化风险平价 | 月末：QQQ、IEF、GLD 各自过去 63 个交易日日收益标准差 σ，权重 ∝ 1/σ（归一化到 100%），下一交易日收盘调仓 | 无 |

**试验次数：8**（R1、R1b、R2、R2b、R3、R3b、R4、R5）。另有参照 QQQ 买入持有（不算试验）；基准 ONEQ 买入持有。
8 次试验的单侧 5% Bonferroni t 门槛 = 2.50，只报告（判定用下面 0.6 节用户给定的 t ≥ 2）。

### 0.5 区间（ETF 历史决定，每条规则用它能用的最长历史）

- 入场收盘日 S = 规则用到的所有 ETF（含基准 ONEQ）都已有收盘价、且信号已能计算的第一个交易日之后的第一个可交易日
  （R2、R5 是月度规则：S = 第一个能出信号的月末之后的下一个交易日）。信号可以用 ONEQ / IEF 上市之前的 QQQ / SPY 历史"预热"。
- 结束：2026-09-30。
- 预计（以实际数据首日为准，运行时打印）：R1、R2、R2b、R3b 约 2003-10（ONEQ 上市）起；R5 约 2005-02（GLD 2004-11 上市 + 63 天）起；
  R1b、R3 约 2011-10（USMV 上市）起；R4 约 2013-04（MTUM 上市）起。
- **两半**：把每条规则自己的评估区间按交易日数对半分（前一半 / 后一半），基准和参照用同样的两半。

### 0.6 通过标准（相对 ONEQ 买入持有，均扣除成本；A 或 B 满足其一即"通过"）

- **A（收益更高）**：全区间、前一半、后一半三段的 CAGR 都高于 ONEQ，**且**全区间月度超额收益（规则 − ONEQ）的 t 值 ≥ 2。
- **B（更稳且不太贵）**：全区间、前一半、后一半三段都满足：最大回撤比 ONEQ 浅至少 10 个百分点，**且** CAGR 落后 ONEQ 不超过 3 个百分点。
- 每条规则另报告：相对 QQQ 的 CAGR 差和回撤差、波动、夏普、卡玛、换仓次数、成本拖累、各资产持有时间占比、逐年表。
- 解读时说明：IEF / 黄金在 2003–2020 利率下行期有利，2022 年股债同跌对 R1/R2/R5 的"避险腿"不利——这是真实历史，不做事后调整。

**解读**
- 和之前的进出择时一样，这些规则本质上是"保险"：2003–2015（含 2008）回撤浅 25–44 个点、收益接近 ONEQ；但 2015 年以后几乎全部变成"付保费"，
  后一半 CAGR 落后 ONEQ 1–10 个点，回撤也只浅 1–17 个点。B 条件都是卡在**后一半**（回撤不够浅或收益落后太多）。
- 最接近的是 R2b（双动量，QQQ/SPY 取强者）：全区间 +13.9% 对 ONEQ +13.3%、回撤 −28.6% 对 −55.1%，前一半两条都满足，
  但后一半落后 1.1 个点、回撤只浅 6.7 个点（要 10），t 值 −0.02。前一半的优势主要是 2008 年一次躲过。
- 2022 年股债同跌，"跌了就换成 IEF"的规则没能躲开（IEF 当年约 −15%），R1 只比 ONEQ 少亏 1.6 个点。
- R1b、R3（换成低波 USMV）几乎就是 QQQ 的翻版：USMV 在急跌里也跌，回撤和 ONEQ 一样深。R4（MTUM/USMV）全区间落后 4.9 个点，因子 ETF 本身就跑不赢纳斯达克。
- R5（风险平价简化版）平均 58% 债券，回撤只有 −18.7%，但后一半每年少 10.5 个点，B 条件的"落后不超过 3 个点"差得最远。
- 再次提醒：2015–2026 已经在前几项研究里看过，这里没有样本外；即使有一条"通过"也只是弱证据。结论：**不建议按这 8 条规则切换持仓**；
  不再调参数重试。
