# SEC 免费数据的两类新信号（内部人买入 Form 4、13F 抄作业）：研究台账

> 代码 `scripts/research_sec_alt.py`，测试 `tests/test_research_sec_alt.py`，结果 `output/research_only/sec_alt/`。
> 股价用冻结面板 `research_cache/reversal_2012_2026/prices/daily_panel.csv.gz`（纳斯达克股票，含已退市），
> 加载复用 `scripts/research_livermore.load_window`（同一套总收益指数、退市终值、继承证券拼接），成本复用
> `scripts/research_reversal_dev.order_cost / half_spread`（IBKR Pro Tiered），账户 1 万美元，只做多，现金 0 利息。

## 0. 事先登记（2026-10-05，在下载全部数据、计算任何收益之前写下）

### 0.1 先说清楚

- 这两类信号本仓库**从没试过**；但 2014–2026 的 ONEQ / QQQ 走势已经被前面十几项研究反复看过，学术文献
  （Cohen-Malloy-Pomorski 2012 的"机会型内部人"、各种 13F 抄作业研究）结论也大致知道。所以这不是严格的样本外，
  只能算"教科书规则在已知年份上的一次性检验"：规则写死，不调参，每个配置跑一次，结果不论好坏照记。
- 面板只有纳斯达克股票（曾进入每周成交额前 300 名的约 3,200 只）。内部人买入大量发生在小盘股、纽交所股票上，
  13F 大户（伯克希尔）的重仓多数在纽交所——**面板外的股票一律跳过并计数**，这是本研究最大的局限，结果里逐项报告覆盖率。

### 0.2 数据（全部来自 SEC 免费数据，原始文件只放本机 `research_cache/sec_alt/`，不进 Git）

- User-Agent 用 `src/io/sec_contact.py`（不打印），每秒最多 3 次请求。
- **Form 4**：SEC "Insider Transactions Data Sets" 季度 ZIP（`/files/structureddata/data/insider-transactions-data-sets/YYYYqN_form345.zip`），
  2011q1 – 2026q2（SEC 截至 2026-10-05 只发布到 2026q2，即 2026-06-30 以前提交的表格；**2026-07、08 没有新信号**，
  已持仓照常到期卖出）。用到的表：SUBMISSION（提交日 FILING_DATE、表格类型、发行人 CIK / 代码）、REPORTINGOWNER（申报人 CIK、身份）、
  NONDERIV_TRANS（非衍生品交易：交易代码、日期、股数、价格）。
- **市值**（只给 I3 用）：XBRL frames API `dei/EntityCommonStockSharesOutstanding`（封面流通股数），每个日历季度一个文件
  （CY2012Q4I – CY2026Q2I）。某日可用的股数 = `end + 45 天 ≤ 该日` 的最新一条（frames 不给提交日，用 45 天保守滞后）；
  市值 = 股数 × 信号日（提交日）或之前最近一个原始收盘价。没有股数的股票不进 I3（计数）。
- **13F**：EDGAR submissions JSON 列出每家机构的 13F-HR 原始申报（不用 13F-HR/A 修正、不用 13F-NT），取受理时间
  （acceptanceDateTime）和 information table XML（发行人名、CUSIP、市值、股数类型、看涨 / 看跌）。
- **CUSIP → 面板证券**：13F 只给 CUSIP 和发行人名，面板没有 CUSIP。做法：发行人名规范化后与 `security_master.csv`
  的公司名 / 曾用名匹配，再人工核对（只核对"是不是同一只证券、哪个股票类别"，在算任何收益之前完成），结果存
  `output/research_only/sec_alt/cusip_map.csv`。匹配不到面板的 = 不可定价，跳过并计数。

### 0.3 共同设定

- **区间**：账户在 **2013-12-31 收盘**为 1 万美元现金（F1/F2 当日按最近一份已受理的 13F 建仓），第一天收益 2014-01-02，结束 **2026-08-31**（面板最后一天）。
- **判定的两半**：前半 **2014-01-02 – 2019-12-31**，后半 **2020-01-02 – 2026-08-31**（同一次连续回测切段，起点用上一段最后收盘做基数）；全期用于月度超额 t 值。
- **基准**：ONEQ 总收益（Yahoo 复权收盘，`research_cache/benchmarks/chart_ONEQ.json`），2013-12-31 收盘买入持有，扣一次买入成本；QQQ 同样处理，只报告。
- **防偷看**：Form 4 只用 **提交日**（不用交易日）；入场 = **提交日之后的第一个交易日收盘**（EDGAR 17:30 以后受理的表格提交日记为下一工作日，
  所以"提交日后一个交易日收盘"一定晚于受理时间）。13F 用受理日，**受理日之后的第一个交易日收盘**调仓（法定 45 天截止日之内，实际日期为准）。
  CMP 的"例行 / 机会型"分类只用上一年 1 月 1 日以前提交的表格。退市股按面板终值收益结算。
- **执行与成本**：收盘成交；每单 IBKR Tiered 佣金（每股 0.0035，最低 0.35，最高 1%）+ 交易所 / 清算费 + 卖出 SEC / FINRA 费 + 半价差
  （按当周成交额排名 2–8 bp，不在前 300 名的 10 bp，且不少于 0.5 美分 / 股）；整股约束不建模（按金额买入）。
- **试验次数：5**（I1、I2、I3、F1、F2）。5 次试验的单侧 5% Bonferroni t 门槛 = 2.33，只报告。

### 0.4 规则

**内部人买入的共同过滤**（一份 Form 4 = 一个"申报"）：
- 表格类型 `4`（不用 4/A 修正、Form 5）；交易代码 **P**（公开市场买入）、取得（A）、单价 > 0、交易日 ≤ 提交日；
  证券名称含 preferred / note / debenture / warrant / unit / right 的剔除。
- 申报人身份含 **Director 或 Officer**（只是 10% 大股东、Other 的不算）。
- **机会型（排除例行）**：申报人（按申报人 CIK）在 Y 年被视为"例行交易者"，当且仅当存在同一个日历月 m，使他在 Y−1、Y−2、Y−3 三年的 m 月
  **每年都有**公开市场交易（P 或 S，任何公司；只用 Y 年 1 月 1 日之前提交的表格）。例行交易者在 Y 年的买入全部剔除；
  其余人（包括历史不满 3 年的）都算机会型。与 CMP 原文的差别：原文只把"有 3 年历史且不是例行"的人算机会型，历史不足的不分类；
  这里按任务的写法只做"排除例行"。
- **发行人 → 面板证券**：发行人 CIK 在 `security_master.csv` 里只有一只证券就用它；多只（多类股）时用 ISSUERTRADINGSYMBOL 与
  `ticker_intervals.csv` 匹配（优先提交日落在区间内的）；对不上就跳过（计数）。入场日面板没有收盘价的跳过（计数）。

| 编号 | 规则 |
|---|---|
| **I1** | 一份合格申报里同一申报人 P 交易合计金额（股数 × 价格）**≥ 5 万美元** → 信号。入场 = 提交日后第一个交易日收盘；**持有 63 个交易日**（约 3 个月）后收盘卖出；最多 10 只，每只买入 = 当时净值 / 10（不超过现金；不足 100 美元或不足目标 20% 不买）。满 10 只时新信号放弃；已持有的股票再出信号不加仓、不延长。同一天多个信号按金额从大到小。 |
| **I2** | **集体买入**：同一发行人在交易日 30 天窗口内有 **≥ 3 个不同的**机会型董事 / 高管做 P 买入（每人不设 5 万门槛，窗口内合计 ≥ 5 万美元）；信号日 = 使人数达到 3 的那份申报的提交日。之后同一发行人 30 天内不重复触发。持有、仓位同 I1，同日多个按合计金额排序。 |
| **I3** | I1 再加：信号日市值 **< 50 亿美元**（定义见 0.2；无股数数据的不进）。 |
| **F1** | **伯克希尔**（CIK 1067983）每份 13F-HR：剔除看涨 / 看跌期权行和债券（PRN）行，同一 CUSIP 合并，按申报市值取**前 10**；其中能在面板定价的股票**等权、满仓**持有。每份新 13F 受理后第一个交易日收盘全部重新等权（先卖后买；某只的调整额 < 净值 1% 时不动）。0 只可定价时持现金。 |
| **F2** | 三位长期、只做多的知名经理人（**结果出来之前选定**）：**Akre Capital Management**（CIK 1112520，Chuck Akre）、**Gardner Russo & Quinn**（CIK 860643，Tom Russo）、**Ruane, Cunniff & Goldfarb**（Sequoia 基金，CIK 728014，2018 年改组后为 CIK 1720792；同一报告期取先受理的一份）。每人最新一份 13F 的前 10（同 F1 的处理）取并集，可定价的**等权满仓**；三人任何一份新 13F 受理后第一个交易日收盘重新等权（规则同 F1）。 |

选人说明：三位都是公认的长期集中持股、低换手、只做多的价值型经理人，整个 2013–2026 都在报 13F。选择时没有看本研究任何结果；
但他们"有名"本身含有一定的事后幸存者偏差（有名是因为过去做得好），解读时要记住。

### 0.5 通过标准（相对 ONEQ，扣成本后；A 或 B 满足其一 = 通过）

- **A**：前半、后半两段的 CAGR 都高于 ONEQ，**且**全期（2014-01 – 2026-08）月度超额收益（策略月收益 − ONEQ 月收益）的 t 值 ≥ 2。
- **B**：前半、后半两段都满足：最大回撤比 ONEQ 浅至少 10 个百分点，**且** CAGR 落后 ONEQ 不超过 3 个百分点。
- 全套指标（全期和两半都报）：CAGR、对 ONEQ / QQQ 的 CAGR 差、年化波动、最大回撤、最长回撤（交易日）、夏普、索提诺、卡玛、
  信息比率（IR）、对 ONEQ 的 beta / 年化 alpha、跑赢 ONEQ 的年份占比、最差年 / 最差月、交易笔数、胜率、盈亏比（profit factor）、
  年换手、成本拖累；另报告覆盖率（信号 / 13F 前十里有多少能定价）和平均仓位。

## 结果（2026-10-05，按第 0 节跑一次；`PYTHONPATH=. .venv/bin/python scripts/research_sec_alt.py`）

**运行记录**（规则、参数、标准都没改）：
1. 第一次在读缓存的 Form 4 表时报错停止（个别交易日期写错，读回时整列没被识别成日期），没有算出任何收益；改为逐列转换、坏日期丢弃，重跑。

**覆盖率（最大的局限）**：
- I1：2014 年以后 56,928 个合格信号，**83% 的发行人不在面板里**（小盘、纽交所），能定价的 6,924 个；10 个仓位几乎一直满（平均 9.9 只），
  其中 5,922 个因满仓被放弃，实际只买了 502 笔——等于"先到先得"地抽样。I2 8,989 个信号，能定价 1,025 个，买了 451 笔。
  I3 在 I1 的 6,924 个里去掉无股数数据 946 个、市值 ≥50 亿 1,495 个。例行交易者的买入剔除 28,399 份。
- F1：53 份 13F，前十里平均只有 2.0 只能定价（按市值占前十的 35%）；2013–2015 几乎为 0（主要是 DirecTV），2016 年后主要是苹果、卡夫亨氏、Charter、动视。
  所以 F1 实际上不是"伯克希尔克隆"，而是"伯克希尔前十里的纳斯达克股票"，其中 2017–2026 大部分时间是苹果 + 卡夫亨氏两只。
- F2：158 份 13F，前十平均 2.7 只能定价（占前十市值 22%），27 份为 0（Russo 的持仓大多是外国股和纽交所股）。

**解读**：
- I2（集体买入）前半很好（+30% / 年），后半落后 ONEQ 2.5 个点，回撤深 15 个点；全期 t = 1.15，不到 2。I1 正好相反（前半落后、后半领先），
  两半不一致，说明更像运气 / 少数大赢家（Sezzle、Moderna、Tandem 等单笔 +200% 以上），而不是稳定的超额。I3（小盘）明显更差。
- 13F 抄作业两个都落后 ONEQ 3–5 个点 / 年，主要原因是只能抄到一小部分持仓、价值股这十年整体跑输纳斯达克；F2 前半回撤浅 4 个点，不够 10 个点。
- 局限：面板只有纳斯达克、曾进前 300 名的股票，Form 4 信号大部分用不上；2026-07、08 没有 Form 4 数据；13F 只用原始申报（伯克希尔偶尔后补的保密持仓不计）。
  这些都不足以改变"5 个都不通过"的结论；要真正检验内部人买入，需要覆盖全市场（含纽交所、小盘）的价格数据，那是另一项研究，需要另行登记。
