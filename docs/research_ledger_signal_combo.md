## 0. 事先登记（2026-10-14，写组合代码、算任何组合结果之前写下）

### 0.1 为什么做、以及必须先说清楚的事

- 之前有几项研究"差一点"：单独看都没过事先标准，但方向对、t 在 1–2.3 之间。想法：如果它们的超额收益（相对各自匹配基准的那一部分）
  **彼此相关性低**，按固定权重合起来，噪音会部分抵消，合起来的 t 可能比任何一个单独的都高（分散化）。
- **诚实声明（结论必须带着读）**：
  1. **每一个组件都是看过样本内结果之后才挑出来的**（它们之所以被叫作"差一点"，正是因为看过了结果）。所以本研究受**选择偏差**影响：
     即使组合"通过"，也只是很弱的证据，**最多只能进前向观察（不投钱、按月记录）**，不能据此投真钱。
  2. 2016–2026 的每一年都已在前面二十多项研究里反复看过，**没有样本外**。
  3. 为了不自欺，多重检验门槛**按全部组件研究的全部试验次数**算（0.7 节，约 18.5 万次），同时报告只按本研究 3 个组合算的"本地门槛"；
     另外报告按同一试验次数去运气的夏普比率（DSR，0.8 节）。

### 0.4 Step A（诊断，不判定）

- 每个组件、每折，用它自己冻结的规模（1 万美元；MN 叠加 k = 20%；S3Yb 18 个 1 万美元账户）从折的第一天重新跑，得到日收益，再算月度超额 e = 组件 − 匹配基准（0.2 节）。
- 报告：两折合起来（128 个月）的 7 × 7 相关系数矩阵（Pearson）、每折的相关矩阵；每条流的年化均值、年化跟踪误差、月度 t、两折各自的 t；
  SEL-A（29876）作为 RSI2 的另一版本只报告。
- **每单位名义金额的超额流**（定权重用）= e ÷ 该组件在冻结规模下的名义金额占比：SP、IDX 除以 1；MISP / PROF / ML 除以 0.2；RSI2、S3Yb 除以 0.25。

### 0.5 Step B 的三个组合（权重在看到任何组合结果之前按下面的公式定死；最多 3 个）

记 h_i = 组件 i 的名义金额 ÷ 建仓时账户净值（1 万美元）。

- **C1 等风险 + 固定跟踪误差**（保证金账户）：对折 f，用**另一折**的每单位名义超额流（0.4 节）算年化波动 σ_i 和相关矩阵 ρ；
  h_i = c / σ_i，c 使事前跟踪误差 √(hᵀΣh) = **4%/年**（即 c = 0.04 / √(Σ_ij ρ_ij)）。然后按顺序施加上限：
  SP ≤ 0.5、IDX ≤ 0.5、MISP / PROF / ML 各 ≤ 0.5、RSI2 ≤ 0.25、S3Yb ≤ 0.25（超出的截到上限，**不把多余的分给别人**）；
  最后做 Reg T 初始保证金检查（最坏情况：所有做T 同时满仓）：0.5 × [(1 + Σ_MN h + h_RSI2 + h_S3Yb) + Σ_MN h] ≤ 0.95，不满足就把 MN 三个、RSI2、S3Yb 的 h 按同一比例缩小到正好满足。
  报告实际权重和事前跟踪误差（上限生效时会低于 4%）。用另一折定权重 = 权重里不含本折的任何信息。
- **C2 等名义金额**（保证金账户）：7 个组件各 h = **0.10**（Reg T 最坏情况 0.5 × (1 + 0.3 + 0.2 + 0.3) = 0.90 ≤ 0.95）。
- **C3 只做多、可在 1 万美元现金账户里执行的子集**（不做空、不融资）：IDX、RSI2、S3Yb 各 h = **0.10**：
  70% ONEQ + 10% X10 组合 + 20% 现金备用金（RSI2、S3Yb 各 10%，只在它们的加仓信号出现时用来买 QQQ / 个股，卖出后回到现金）。

### 0.6 实盘式组合模拟（"账本"），不是把几条收益流简单相加

每折从 1 万美元开始，建仓时按 0.5 节的 h 分配，**折内各部分之间不再调回目标权重**（登记的简化：各部分各自运行、自然漂移；漂移照实报告）。
每个部分都用组件自己的冻结引擎、**按它在这个 1 万美元账户里的实际金额**重新跑（整股、每单最低 0.35 美元等规模效应因此按真实大小计）：

| 部分 | 在账本里怎么持有 | 引擎和规模 |
|---|---|---|
| ONEQ 底仓 | C1 / C2：(1 − h_SP − h_IDX) × 1 万美元；C3：(1 − h_IDX − h_RSI2 − h_S3Yb) × 1 万美元。建仓买一次（ONEQ 半价差 2 bp + IBKR 佣金） | `megacap.buy_hold` |
| SP | h_SP × 1 万美元的 SP Top10 组合（等权 10 只，25% 调仓带） | `megacap.simulate(account = h_SP × 1 万)` |
| IDX | h_IDX × 1 万美元的 B100 S-MISP X10 组合 | `megacap.simulate(account = h_IDX × 1 万)` |
| MISP / PROF / ML（只 C1 / C2） | 叠加：多买 h × 1 万美元 QQQ（保证金贷款）+ 做空 h × 1 万美元的输家篮子。叠加的盈亏 = 引擎账户净值 − 同一账户 100% QQQ 买入持有 | `short_overlay.simulate(Cfg(信号, 10, k = h, "MN"), account = 1 万)`：整股做空、Tiered 佣金和规费（卖空收 SEC 费和 TAF）、半价差、分档借券费（0.5% / 2% / 难借代理 10%，short_overlay 0.5 节）、保证金贷款 EFFR + 1.5%（空头所得不抵贷款）、Reg T |

- 账本净值 = ONEQ 底仓 + SP + IDX + Σ 叠加盈亏（+ C3 的备用金现金）。现金不计利息（IBKR 第一个 1 万美元无利息；本账户不到 10 万美元，空头所得无利息）。
- **保证金检查（C1 / C2，每个交易日收盘）**：维持要求 ≈ 25% × 所有多头市值（ONEQ、SP、IDX、MN 里的 QQQ、做T 加仓）+ 30% × 空头市值；账本净值低于要求记为"违约日"。
  有任何违约日 → 该组合判为**不可执行**（本研究不模拟强平）。只用收盘价，盘中更极端的情况看不到（偏乐观）。
- **孪生组合（twin，信号全关掉）**：同样的结构、同样的金额，但 SP 换成 ONEQ、IDX 换成不剔除的 B100、MN 叠加和做T 全部不做（C3 的备用金仍是现金）。
  账本 − 孪生 = "信号本身"带来的部分（例如 IDX 里"B100 比 ONEQ 更像 QQQ"的那 2–3 点/年会在孪生里一并出现，从而被扣掉）。
- **简单相加的诊断（只报告）**：ONEQ 月收益 + Σ h_i × 每单位名义超额流（0.4 节，冻结规模、无组合层面的成本、融资和规模效应）。

### 0.7 判定（每个组合）

每折（同之前台账）：**A** = 该折扣成本年化 > ONEQ 年化，且该折月超额（账本 − ONEQ）t ≥ 2；**B** = 最大回撤比 ONEQ 浅 ≥ 10 个百分点，且年化落后 ONEQ ≤ 3 个百分点。

组合**通过**要同时满足：
1. 两折都满足 A 或 B；
2. 两折合起来的月超额 t（账本 − ONEQ）≥ **全家族 Bonferroni 门槛**；
3. 账本 − 孪生的月超额：两折均值都 > 0，且两折合起来的 t ≥ 同一门槛（"合起来真的是信号带来的"，不是 QQQ 比 ONEQ 好、也不是多持了仓位）；
4. C1 / C2 没有保证金违约日。

- **全家族门槛**：单侧 5%、Student t（自由度 = 月数 − 1）、Bonferroni 试验数 = 所有组件研究登记过的全部试验 + 本研究 3 个：

  | 研究 | 试验数 |
  |---|---|
  | t_grid（RSI2 是从 184,320 个配置里挑出来的） | 184,320 |
  | fundamentals（sp、盈利能力） | 100 |
  | qc_factors（S/P） | 40 |
  | short_overlay（MISP、PROF、ML） | 32 |
  | index_exclusion（IDX） | 24 |
  | selective_t（S3Yb） | 18 |
  | ml_cross_section（GBRT） | 8 |
  | 本研究 | 3 |
  | **合计** | **184,545** |

- **本地门槛**：只按本研究 3 个组合算（同样单侧 5%、Student t）。只满足 1、3（t ≥ 本地门槛）、4 和"2 用本地门槛"的记"**本地名义通过**"——这不算通过，只说明"如果不计组件挑选的代价，看起来如何"。
- 研究判定：任一组合"通过" = 通过（只进前向观察）；否则不通过。

### 0.8 去运气夏普比率（DSR，只报告）

Bailey & López de Prado（2014）：对每个组合两折合起来的月超额（账本 − ONEQ，以及账本 − 孪生）算月度夏普、偏度、（非超额）峰度；
试验数取 0.7 节的 184,545（另报 3）；"各试验夏普的方差"取 7 条 Step A 超额流（两折合起来）月度夏普的样本方差（另报它的 ½ 倍和 2 倍）。DSR ≥ 0.95 才算过。

### 0.9 只报告的诊断

- 账本的分项：每个部分对账本的年化贡献（点/年）、交易成本、借券费、融资利息（占账本净值 / 年）、成交笔数、做空只数、做T 次数；整股导致"一股都买不起"的情况（S3Yb 小账户）。

- 把 ONEQ 底仓换成 QQQ 的版本（"100% QQQ 底仓"，只报告，不判定：它多出来的是 QQQ 比 ONEQ 好的那部分，不是信号）。

### 1.6 测了什么、没测什么

- 测了：7 个组件（含 S/P 的本地代理）在 2016-01 至 2026-08 两折上的超额流、相关矩阵和 t；3 个事先定死权重的组合，作为一个 1 万美元 IBKR 账户的实盘式模拟
  （每个部分用自己的冻结引擎按实际金额重跑：整股、Tiered 佣金和规费、半价差、分档借券费、EFFR + 1.5% 保证金利息、空头所得不抵贷款、每日维持保证金检查），
  对 ONEQ 的 A / B、两种 Bonferroni 门槛、对"信号全关"的孪生、简单相加的对照、100% QQQ 底仓的对照、去运气夏普。
- 没测：QuantConnect 上真正的 S/P 前 10 名（本地代理的股票池不同，而且本地 sp 本身就显著跑输）；折内各部分之间的再平衡（登记为不调）；
  按波动率择时 / 按情绪择时的权重；只用两折之外的任何权重优化（例如按样本内夏普加权）——那样做会把选择偏差放得更大。
  这些如果要做，都必须重新登记、计入试验次数。
- 诚实提醒（重复 0.1 节）：每个组件都是看过结果才挑出来的；即使有组合通过，也只能进前向观察。这次没有一个通过，连"本地名义通过"都没有。

### 1.7 结论

- **不通过**。在 2016–2026 的重叠期里，7 个"差一点"的信号相对各自基准的超额，只有 S-MISP 空头腿接近显著（t 1.95）；其他 6 个均值接近 0 或为负
  （S/P 的本地代理每年 −14.5%）。彼此相关性确实低（平均 0.08，但三个空头腿之间 0.5 左右），可是**分散化只能降噪，不能把一堆接近 0 的均值加成一个显著的正数**。
- 等风险加权（C1）反而把权重给了波动最小、但均值也最接近 0 的组件；C1 在 H2 对 ONEQ 的 +3.3 点里一大半来自"B100 比 ONEQ 像 QQQ"，对孪生合并 t 只有 0.39。
- 1 万美元只做多的子集（C3）对 ONEQ 每年落后 2.3–2.6 点：为做T 留的现金拖累大于做T 的收益；S3Yb 在这个规模下多数股票一股都加不了。
- 不建议用真钱；也不建议把任何一个组合放进前向观察。已经在前向观察里的 S3-Yb、SEL-A / SEL-P、S-MISP N10 k20 MN（B1–B3）照原计划单独观察，不受本研究影响。
