# 多角度评估记分卡（`quant/evaluation/scorecard.py`）

> 主人的要求：“评价方式也有很多种，不止是收益率，你可以多角度去评价。”
> 本文说明记分卡里**每一个指标**：定义和公式、单位和频率、白话意思、怎么看、要注意什么。
> 代码名字保持英文；测试在 `tests/quant/test_scorecard.py`。
> 第 6 节是用它给前瞻观察的候选策略打的分（`studies/scorecard_candidates.py`，2026-10-26）。

## 0. 先说清楚：它不是通过标准

记分卡只**描述**一个策略，不**判决**。每个研究事先登记的判决规则不变：对 ONEQ 的 A / B 标准
（`quant.evaluation.criteria`，A＝收益更高且月度超额 t ≥ 2，B＝回撤浅 10 个百分点且收益差不超过 3 个百分点）。
不能在看完记分卡以后再挑“哪个指标好看就用哪个”来说策略通过了——那等于又多做了几十次试验。
如果某个研究想用记分卡里的指标做判决，必须在跑之前写进台账的事先登记块。

## 1. 怎么用

```python
from quant.evaluation.scorecard import scorecard, compare

card = scorecard(
    daily_returns,                 # 策略每期收益（小数，0.01 = 1%），日或月
    oneq=oneq_returns,             # ONEQ 每期收益（可选，所有“相对”指标都要它）
    qqq=qqq_returns,               # QQQ 每期收益（可选，只用于“比 QQQ 多赚多少”）
    rf=tbill_returns,              # 国债每期收益（可选；不给就按 0，表里会注明）
    trades=trade_log,              # 交易记录（可选），每行一笔单
    meta={"n_trials": 40, "oos_status": "none", "permissions": ["margin"], "margin_leverage": 1.5,
          "positions": 2, "min_account_usd": 3000, "data_dependence": "只要日收盘价"},
)
compare({"策略": card, "ONEQ 本身": scorecard(oneq_returns, oneq=oneq_returns, rf=tbill_returns)})
```

每个类别也可以单独调用（`return_metrics`、`risk_adjusted_metrics`、`drawdown_metrics`、`tail_metrics`、
`consistency_metrics`、`market_metrics`、`utility_metrics`、`path_metrics`、`practicality_metrics`、
`confidence_metrics`），返回 `{指标名: 数值}`。`drawdown_episodes` 返回每一段回撤的明细表（前高、谷底、回本的日期）。

### 1.1 输入约定

| 项目 | 约定 |
|---|---|
| 频率 | `freq="D"`（一年 252 期）或 `"M"`（一年 12 期）；不给就按日期间隔自动判断（中位间隔 ≤ 6 天是日，27–32 天是月）。月数据可以用月末日期，也可以用月度 PeriodIndex |
| 缺失值 | 策略收益里不许有 NaN（会报错），请先截到真正有收益的那几期；基准开头的 NaN（上市前）会自动去掉 |
| 无风险利率 `rf` | 每期的国债收益，频率与策略相同；策略是月数据、rf 是日数据时，自动按月复利；必须覆盖策略的每一期，否则报错 |
| 基准对齐 | 相对指标只用两个序列**都有**的时段：两个都是日数据就用共同交易日（基准缺的那天，策略那天的收益也不用）；否则都换成自然月、用共同月份，并且**日数据那一边首尾不满一个月的月份去掉**（第一个收益比月初晚 4 天以上、或最后一个收益比月末早 4 天以上），免得拿半个月和整月比。月数据一边按原样当整月 |
| 价值路径 | 第一期之前的净值是 1.0，所以第一期就亏也算回撤（与 `metrics.core_metrics` 相同） |
| 交易记录 `trades` | 每行一笔单，覆盖与收益序列相同的时段；可选列 `traded`（这笔成交金额 ÷ 当时账户价值）、`cost`（这笔佣金加价差 ÷ 当时账户价值） |
| 重抽样 | 平稳块重抽样（Politis–Romano），平均块长 `block_months`（默认 12 个月），`n_boot` 次（默认 2000），固定种子 `seed`，同样输入永远得到同样结果；`n_boot=0` 跳过所有重抽样 |

`meta` 可以给的键（都可选）：`n_trials`（选出这个策略前一共试了几个版本）、`sr_trials_var`（这些版本月度夏普的方差）、
`oos_status`（`passed` / `failed` / `none`）、`min_account_usd`、`permissions`（取自 `margin`、`short`、`options`、
`futures`、`leveraged_etf`、`inverse_etf`、`crypto`；空列表＝普通现金账户）、`positions`（通常同时持有几只）、
`timing_sensitive`（是否要盘中下单、挂限价单或在固定时刻下单）、`margin_leverage`（保证金账户里 总持仓 ÷ 净值）、
`maintenance_margin`（维持保证金比例，默认 0.25）、`data_dependence`（文字），以及没有交易记录时直接给的
`trades_per_year`、`turnover_one_way_per_year`、`cost_drag_per_year`。

### 1.2 表的列

| 列 | 意思 |
|---|---|
| `family` / `family_zh` | 十个类别之一（英文 / 中文） |
| `key` | 指标名 |
| `value` | 数值（文字类指标是字符串，缺失是 NaN） |
| `unit` | 单位，见下表 |
| `freq` | 这个数是用什么频率的数据算的：`D` 日、`M` 月、`Y` 自然年、`D bootstrap` / `M bootstrap` 重抽样、`trades` 交易记录、`meta` 研究者提供、`rule` 按固定规则打分 |
| `meaning_zh` | 一句白话 |
| `note` | 这个数为什么缺失、或者要打多少折扣（例如“未提供无风险利率，按 0 计”） |

| 单位 | 意思 |
|---|---|
| `frac` | 小数：0.10 = 10%，−0.30 = 跌 30% |
| `frac/yr` | 每年的小数：0.08 = 每年 8% |
| `pct` | 已经乘过 100 的百分点：12.5 = 12.5% |
| `ratio` / `number` | 比值 / 无单位的数 |
| `x` | 资金的倍数：1 = 满仓，2 = 两倍杠杆 |
| `usd` | 美元 |
| `years` | 年（期数 ÷ 每年期数） |
| `count`、`count/yr` | 次数、每年次数 |
| `prob` | 概率，0–1 |
| `t` | t 统计量 |
| `bool`、`text`、`score1-5` | 是 / 否、文字、1–5 分 |

### 1.3 记号

`r_t`：第 t 期收益；`P`：每年期数（日 252、月 12）；`n`：期数；`rf_t`：同期国债收益；`ex_t = r_t − rf_t`（超额收益）；
`m_t`：自然月收益（日数据在月内复利）；`b_t`：ONEQ 同期收益；`V_0 = 1`，`V_t = ∏(1 + r_s)`（价值路径）；
`peak_t = max(V_0..V_t)`（前高）；`DD_t = V_t / peak_t − 1`（回撤，≤ 0）。

**哪些用月数据**：分布（尾部）、稳定性、与大盘关系、凯利、t 值都用自然月收益，这样日数据和月数据输入的结果可以互相比较；
收益、回撤、夏普 / 索提诺、CRRA 用输入本身的频率。

## 2. 十类指标

### 2.1 收益（return）

**`cagr` 年化复合收益率**
- 公式：`(∏(1 + r_t))^(P / n) − 1`（`metrics.cagr_of`）。单位 `frac/yr`，输入频率。
- 白话：把整段的总涨幅折算成“每年稳定涨百分之几、利滚利”的速度。
- 怎么看：越高越好，但它只看起点和终点，完全不管中间有多难熬（看回撤、路径体验）。
- 注意：日数据按一年 252 个交易日；回测期越短越不可靠，一个特别好的年份就能把它抬很多。

**`mean_return_ann` 平均收益折年**
- 公式：`(1 + mean(r_t))^P − 1`（`mean_return_annualized`）。单位 `frac/yr`，输入频率。
- 白话：先算每期收益的简单平均，再假设每期都正好赚这个平均数、利滚利一年。
- 怎么看：由算术–几何平均不等式，它**不会低于** CAGR（没有任何波动时两者相等）；两者在对数上的差就是“波动拖累”
  （`volatility_drag`）。差得越多，说明波动把平均收益吃掉得越多。它也正好是风险中性（γ = 0）的确定性等价。
- 注意：不是你真正到手的收益，不能拿来规划财富。
- 改过一次（2026-10-26）：最初写成 `mean(r_t) × P`（不复利），和复利的 CAGR 相减时混进了复利项，低波动时拖累会变成负数；
  例如每月固定 +1% 时报出拖累 −0.68%/年。现在的写法每月固定 +1% 时拖累正好为 0。

**`terminal_wealth` 1 万美元最后变成多少**
- 公式：`10000 × ∏(1 + r_t)`（起始金额可用 `start_capital` 改）。单位 `usd`。
- 白话：一开始放 1 万美元、中间不加不取，回测结束时有多少钱。
- 怎么看：最直观；和 ONEQ 的同一行比。
- 注意：不同长度的回测不可比；没扣税。

**`excess_cagr_vs_oneq`、`excess_cagr_vs_qqq` 年化超额收益**
- 公式：在共同时段上 `CAGR(策略) − CAGR(基准)`（都是日数据用共同交易日，否则用共同月份）。单位 `frac/yr`。
- 白话：每年比买入持有 ONEQ（纳斯达克综合指数基金）/ QQQ（纳斯达克 100 基金）多赚几个百分点，负数是少赚。
- 怎么看：ONEQ 是本项目所有通过标准的比较对象；QQQ 只作参考。
- 注意：共同时段可能比策略全段短（看 `years_vs_oneq`），所以它不一定等于 `cagr` 减去基准在策略全段的 CAGR。
  ONEQ 2003-10 才上市，更早的时段要用纳指总收益的估计序列当 `oneq`。

### 2.2 风险调整后收益（risk_adjusted）

**`volatility_ann` 年化波动率**
- 公式：`sd(r_t, ddof=1) × √P`。单位 `frac/yr`，输入频率。
- 白话：收益每年上下晃动的典型幅度（标准差）。
- 怎么看：两倍杠杆大约两倍波动；波动大不一定坏，但会带来波动拖累和更深的回撤。
- 注意：它不分涨跌，涨得猛也算“风险”。

**`sharpe` 夏普比率**
- 公式：`mean(ex_t) / sd(ex_t) × √P`（与 `metrics.core_metrics` 同一算式）。单位 `ratio`，输入频率。
- 白话：比国债多赚的部分 ÷ 波动：每扛一份晃动，换来多少超额收益。
- 怎么看：和基准的夏普比；长周期回测里夏普远高于大盘时，先怀疑过拟合或数据问题。
- 注意：假设收益大致对称；对“平时小赚、偶尔大亏”（负偏、卖保险型）的策略会高估；日数据和月数据算出来略有差别。

**`sortino` 索提诺比率**
- 公式：`mean(ex_t) / √(mean(min(ex_t, 0)²)) × √P`，分母对**所有**期取平均（不是只对亏的期）。单位 `ratio`。
- 白话：同夏普，但只把“跌”的晃动算作风险。
- 怎么看：索提诺比夏普高很多，说明波动主要来自上涨（是好事）。
- 注意：亏损期数少时这个数很不稳定。

**`calmar_mar` 卡玛比率（MAR）**
- 公式：`CAGR / |max_drawdown|`，用整段数据（传统 Calmar 只看最近 36 个月，这里是 MAR 口径）。单位 `ratio`。
- 白话：每吃一份最大跌幅，换来多少年化收益。
- 怎么看：和 ONEQ 同一行比，高说明“同样的最痛一次换来了更多收益”。
- 注意：只看一个最坏点，对回测期有没有包含 2000–2002、2008 极其敏感；回测越长最大回撤越可能更深，所以不同长度不可直接比。

**`ir_vs_oneq` 信息比率**
- 公式：月度超额 `x_t = m_t − b_t`，`IR = mean(x) / sd(x) × √12`（`metrics.t_and_ir`；没有波动时为 0）。单位 `ratio`，月。
- 白话：相对 ONEQ 的超额收益是不是又多又稳。
- 怎么看：和 t 值是一回事：`t = IR × √(年数)`。IR 0.5 要大约 16 年数据才能到 t = 2。
- 注意：β 大于 1 的策略在牛市里 IR 会被大盘涨幅抬高。

**`omega_0` 欧米伽比率（门槛 0）**
- 公式：`Σ max(m_t, 0) / Σ max(−m_t, 0)`，月收益。单位 `ratio`。
- 白话：所有赚钱月份赚的总和 ÷ 所有亏钱月份亏的总和。
- 怎么看：大于 1 说明总体赚多亏少；它用到整个分布，不假设正态。
- 注意：门槛是 0 而不是国债利率；没有亏损月时是无穷大。

**`deflated_sharpe` 打折夏普（Deflated Sharpe Ratio）**
- 公式（Bailey 与 López de Prado 2014，`criteria.deflated_sharpe_n`）：
  `SR0 = √V × ((1 − γ_E) Φ⁻¹(1 − 1/N) + γ_E Φ⁻¹(1 − 1/(N e)))`，
  `z = (SR − SR0) × √(T − 1) / √(1 − skew × SR + (kurt − 1)/4 × SR²)`，`DSR = Φ(z)`。
  `SR` 是月度（不年化）超额夏普，`T` 是月数，`skew`、`kurt`（不减 3）取月度超额收益，`N = meta["n_trials"]`，
  `V = meta["sr_trials_var"]`（各个版本月度夏普的方差），没给时按 `1/T`（真实夏普都为 0 时夏普估计值的抽样方差）。
  单位 `prob`，月。`N < 2` 时为空。
- 白话：扣掉“试了很多个版本、挑最好那个”的运气后，真实夏普大于 0 的概率。
- 怎么看：0.95 以上才算扛住了多重试验；0.5 附近说明和运气分不开。
- 注意：`n_trials` 必须如实记（台账里的试验数，包括失败的）；版本之间高度相关时有效次数更少
  （`criteria.effective_trials`）；`V` 用默认假设时只是粗略估计（表里会注明）。

### 2.3 回撤之痛（drawdown）

**`max_drawdown` 最大回撤**
- 公式：`min_t DD_t`，`V_0 = 1`（`metrics.max_drawdown`）。单位 `frac`（负数），输入频率。
- 白话：从最高点到之后的最低点，账户最多缩水多少。
- 怎么看：问自己“账户少了这么多我会不会卖”。跌 50% 要涨 100% 才回本。
- 注意：月数据看不到月内的最低点，实际更深；它只是一次事件，带很大运气成分（看第 8 类的概率更全面）。

**`max_dd_duration_years`、`max_dd_recovered` 最深回撤的时长、是否回本**
- 定义：最深那段回撤**从前高到回本**的期数 ÷ P，即 `(回本那一期 − 前高那一期) / P`（`drawdown_episodes` 的
  `peak_to_recovery_years`）。例：1 月底是前高、4 月底回到前高，就是 3 个月。到数据结束还没回本就算到最后一期，
  `max_dd_recovered = False`。单位 `years`。
- 白话：最深那次从前高跌下去，到重新回到前高，一共用了几年。
- 怎么看：深度和时长一起看；−40% 一年回本和 −40% 五年回本的体验完全不同。
- 注意：没回本时是“至少这么久”。
- 改过一次（2026-10-26）：最初数的是“低于前高的期数”（回本那一期不算），每段已回本的回撤少算一期
  （日数据少 1 天，月数据少 1 个月），和这里的白话说明对不上。

**`longest_underwater_years` 最长水下时间**
- 公式：`metrics.longest_drawdown(V) / P`：任何一段回撤里，连续低于前高（差超过 1e-12）的最长期数（回本那一期不算）。
  单位 `years`。
- 白话：最长的一次“套牢”有多久（不一定是最深的那次）。
- 怎么看：浅而长的横盘也会让它很大。因为它不算回本那一期，`longest_underwater_years + 1/P ≥ max_dd_duration_years`
  （最深的那段同时也是最长的那段时，两者正好差一期）。

**`ulcer_index` 溃疡指数**
- 公式：`√(mean((100 × DD_t)²))`，对价值路径所有点（含起点）平均（`equity.ulcer_index`）。单位 `pct`。
- 白话：每个时点离前高差多少的“均方根”，跌得深、套得久都会让它变大。
- 怎么看：比最大回撤更能代表整个持有过程的难受程度；可以用 `(CAGR − 国债收益) / ulcer` 自己算“溃疡夏普”（Martin 比率）。
- 注意：依赖数据频率，日和月不直接比。

**`pain_index` 痛苦指数**
- 公式：`mean(|DD_t|) × 100`。单位 `pct`。
- 白话：平均每个时点离前高差多少。
- 怎么看：总是 ≤ 溃疡指数（均方根 ≥ 平均值）；溃疡指数远大于痛苦指数，说明有少数特别深的回撤。

**`drawdowns_over_20`、`drawdowns_over_30`、`drawdowns_over_50` 深回撤次数**
- 定义：一段回撤＝从跌破前高到回到前高（`drawdown_episodes`）；数深度**严格**超过 20% / 30% / 50% 的段数
  （恰好 −50% 不算“超过 50%”）。没回本的最后一段也算。单位 `count`。
- 白话：跌幅超过两成、三成、五成的回撤一共发生过几次。
- 怎么看：一个大熊市只算一次；次数多说明这种痛会反复出现，不是一次性的意外。

### 2.4 尾部风险（tails）

**`worst_day`、`worst_month`、`worst_year` 最糟的一天 / 一个月 / 一年**
- 定义：日收益最小值（只有日输入才有）；自然月复利收益最小值；自然年复利收益最小值（首尾不满一年的年份也算，
  与 `core_metrics` 相同）。单位 `frac`。
- 白话：历史上最倒霉的一天、一个月、一年亏了多少。
- 怎么看：和保证金强平线（`margin_call_drop`）、自己的心理底线比。
- 注意：首尾的不完整年份可能看起来特别好或特别差。

**`var_5_monthly` 5% 风险价值（VaR）**
- 公式：月收益的第 5 百分位（numpy 线性插值），用收益表示，负数是亏损。单位 `frac`，月。
- 白话：大约每 20 个月会有 1 个月比这个数更差。
- 怎么看：一个“正常的坏月份”有多坏。
- 注意：少于约 60 个月时很不稳定；它不告诉你超过这条线以后会亏多少。

**`cvar_5_monthly` 5% 条件风险价值（CVaR / 预期亏损）**
- 公式：所有 ≤ VaR 的月份的平均收益。单位 `frac`，月。
- 白话：最差的那 5% 月份平均跌多少。
- 怎么看：比 VaR 更能反映“真出事时”的损失；CVaR 远低于 VaR 说明尾巴很长。

**`skew_monthly` 偏度**
- 公式：月收益的调整后 Fisher–Pearson 偏度（pandas `skew`）。单位 `number`。
- 白话：负数＝偶尔会大跌，正数＝偶尔会大涨。
- 怎么看：“负偏 + 高夏普”是危险信号（像卖保险：平时小赚、偶尔大亏，夏普会高估它）。

**`excess_kurtosis_monthly` 超额峰度**
- 公式：月收益的偏差校正超额峰度（pandas `kurt`，正态分布为 0）。单位 `number`。
- 白话：越大说明极端月份（大涨或大跌）越常见。
- 注意：一两个极端月份就能把它推得很高。

**`tail_ratio_monthly` 尾部比**
- 公式：`|月收益第 95 百分位| / |月收益第 5 百分位|`。单位 `ratio`。
- 白话：好的极端月份和坏的极端月份比，哪个更大。
- 怎么看：大于 1 是右尾（大涨）更粗，小于 1 是左尾（大跌）更粗。

### 2.5 稳定性（consistency）

**`positive_months_share`、`positive_years_share` 赚钱的月份 / 年份占比**
- 定义：`m_t > 0` 的月份占比；自然年收益 > 0 的年份占比（含首尾不完整年份）。单位 `frac`。
- 白话：十个月里有几个月赚钱、十年里有几年赚钱。
- 怎么看：占比高、但最差月很深，说明“经常小赚、偶尔大亏”。

**`years_beating_oneq_share` 跑赢 ONEQ 的年份占比**
- 定义：共同时段里，自然年收益严格高于 ONEQ 的年份占比（与 `relative_metrics` 相同）。单位 `frac`，年。
- 白话：一年一年比，有几成年份跑赢 ONEQ。
- 怎么看：总超额为正但这个数很低，说明超额集中在少数几年，跟起来很难受。

**`rolling_{3,5,10}y_{min,p10,median}` 滚动持有年化收益**
- 公式：对每个连续 36 / 60 / 120 个月的窗口算 `(∏(1 + m))^(12 / 窗口月数) − 1`，窗口每次往后挪一个月（互相重叠）；
  取最小值、第 10 百分位、中位数（`rolling_annualized`）。单位 `frac/yr`，月。数据不够一个窗口时为空。
- 白话：“如果我在任意一个月买入、拿 3 / 5 / 10 年，最差、较差、典型的年化是多少”。
- 怎么看：10 年最差仍为正，说明长期拿着基本不亏；3 年最差很负，说明短期可能很难熬。
- 注意：窗口重叠，不是独立样本；15 年数据只有约 60 个 10 年窗口，而且几乎都重叠。

**`rolling_5y_win_rate_vs_oneq` 5 年滚动胜率**
- 定义：共同月份上，60 个月滚动年化收益策略严格高于 ONEQ 的窗口占比。单位 `frac`，月。
- 白话：任意连续 5 年里，有几成时候跑赢 ONEQ。
- 怎么看：低于 50% 但总超额为正，说明超额靠少数时期。

### 2.6 与大盘的关系（market）

**`beta_vs_oneq` 贝塔**
- 公式：月度超额（减国债）`y = m − rf`、`x = b − rf`，`β = cov(y, x) / var(x)`（ddof = 1，与 `relative_metrics` 同式）。
- 白话：ONEQ 涨跌 1%，策略平均跟着涨跌百分之几。
- 怎么看：β = 1.3 大约相当于 1.3 倍杠杆的大盘；β 高的“超额收益”可能只是多承担了大盘风险。

**`corr_vs_oneq` 相关系数**
- 公式：月收益（不减国债）的皮尔逊相关。单位 `number`。
- 白话：和 ONEQ 同涨同跌的程度，1＝完全同步，0＝没关系。
- 怎么看：接近 1 说明它分散不了大盘风险；低相关的策略和指数放在一起更有用。

**`up_capture_vs_oneq`、`down_capture_vs_oneq` 上涨 / 下跌捕获率**
- 公式：`mean(m_t | b_t > 0) / mean(b_t | b_t > 0)`；下跌捕获同理用 `b_t < 0` 的月份。算术平均版本。单位 `ratio`。
- 白话：ONEQ 涨的月份，策略平均拿到几倍涨幅；ONEQ 跌的月份，策略平均承受几倍跌幅。
- 怎么看：理想是上涨捕获 > 下跌捕获；两者都差不多等于 β 时，策略只是放大或缩小了大盘。
  月收益恰好是 `k × ONEQ` 时两者都正好是 `k`（测试锁定）。
- 注意：Morningstar 的版本用几何平均（复利），数值会略不同（独立核对：QQQ 对 ONEQ 上涨捕获 1.052 对几何版 1.042，
  下跌捕获 0.980 对 0.973）；ONEQ 上涨或下跌的月份少时很不稳定。

**`crisis_<名字>`、`crisis_<名字>_vs_oneq` 危机时段表现**
- 定义：窗口内复利收益 `∏(1 + r) − 1`；减去 ONEQ 同一窗口的收益。默认四个窗口（自然日期）：
  `dotcom_2000_2002`＝2000-01-01 至 2002-12-31，`gfc_2008`＝2008 全年，`covid_2020q1`＝2020-01-01 至 2020-03-31，
  `bear_2022`＝2022 全年（可用 `crises=` 改）。覆盖规则：日数据要求窗口内第一个和最后一个收益离窗口两端都不超过
  4 个自然日；月数据要求有窗口的第一个和最后一个月。不覆盖就是空（注明“数据不覆盖该时段”）。单位 `frac`，输入频率。
- 白话：互联网泡沫、金融危机、疫情暴跌、2022 熊市这几段，策略赚了还是亏了，比 ONEQ 好多少。
- 怎么看：熊市里少亏是很多策略唯一真正的价值；如果每次危机都比 ONEQ 亏得多，回撤之痛会更重。
- 注意：窗口是自然日期，不是精确的高点到低点（2020 的高低点在 2/19 和 3/23）；ONEQ 2003-10 才上市，
  2000–2002 的对比要用纳指总收益估计序列当 `oneq`。两端各允许缺最多 4 天：例如 QQQ 价格从 2000-01-03 开始，第一个收益是
  01-04，01-03 当天的涨跌就不在网络泡沫那一段里。

### 2.7 投资者效用（utility）

**`ce_crra_1`、`ce_crra_2`、`ce_crra_3`、`ce_crra_5` 确定性等价收益（CRRA）**
- 公式：常相对风险厌恶效用 `U(W) = W^(1−γ) / (1−γ)`（γ = 1 时 `log W`）。每期确定性等价
  `CE_p = (mean((1 + r_t)^(1−γ)))^(1/(1−γ)) − 1`，γ = 1 时 `exp(mean(log(1 + r_t))) − 1`；年化 `(1 + CE_p)^P − 1`。
  单位 `frac/yr`，输入频率（`gammas=` 可改）。
- 白话：一个风险厌恶程度为 γ 的人，觉得这个策略“相当于”每年稳拿多少无风险收益。
- 怎么看：γ = 1（对数效用）恰好等于 CAGR——这就是“长期复利最大化”的标准（测试锁定）；γ 越大越看重下跌，CE 越低。
  CE 低于国债收益，说明对这么怕风险的人来说不值得持有。学术上普通投资者的 γ 常取 2–5。
- 注意：假设每期收益独立同分布；任何一期亏光（`r ≤ −100%`），γ ≥ 1 的 CE 就是 −100%。日数据算出来近似“每天调仓”。

**`geometric_efficiency` 复利效率**
- 公式：`CAGR / mean_return_ann`，`mean_return_ann = (1 + mean(r))^P − 1`（它 ≤ 0 时为空）。单位 `ratio`。
- 白话：波动把平均收益“吃掉”之后，还剩几成变成真正的复利收益。
- 怎么看：两者都为正时 ≤ 1；没有波动时正好是 1；杠杆越高越低。

**`volatility_drag` 波动拖累**
- 公式：`ln(1 + mean_return_ann) − ln(1 + CAGR) = P × (ln(1 + mean(r)) − mean(ln(1 + r)))`，由詹森不等式总是 ≥ 0，
  约等于 `σ² / 2`（σ 是年化波动率）。单位 `frac/yr`（对数收益的差，数值上就是每年少了约几个百分点）。
- 白话：因为上下晃，每年白白少了几个百分点。
- 怎么看：加杠杆时拖累按杠杆的平方增长，这就是“加杠杆收益不一定更高”的原因。
- 核对（2026-10-26）：独立重算（Yahoo 含分红价格，截至 2026-10-02）QQQ 3.56%/年（σ²/2 = 3.57%）、ONEQ 2.17%（2.17%）；
  第 6 节的数据上 QQQ（1999-03 至 2026-09）3.61%（3.62%）、ONEQ（2003-10 至 2026-09）2.17%（2.17%）；每月固定 +1% 时正好为 0。
  最初的写法（`mean(r) × P − CAGR`）在前三个例子里分别是 3.20%、1.35% 和 −0.68%，已改。

**`kelly_fraction`、`kelly_ci_lo`、`kelly_ci_hi` 凯利仓位及其区间**
- 公式：月度超额收益 `f* = mean(ex) / var(ex)`（ddof = 1），是 `argmax E[log(1 + rf + f × ex)]` 的连续时间近似。
  区间：对月度超额收益做平稳块重抽样（平均块长 `block_months`），每次重算 `f*`，取第 5、95 百分位（90% 区间）。
  单位 `x`，月。
- 白话：只能在这个策略和国债之间分配时，让长期复利最快的仓位。1＝满仓，2＝两倍杠杆，0.5＝半仓。
- 怎么看：`f* > 1` 表示理论上加杠杆还能更快增长；`f* < 1` 表示满仓已经“太猛”，波动会拖累长期复利。
  区间下沿接近或低于 0，说明连“该不该持有”都不确定。实践中最多用一半凯利。
- 注意：对平均收益极其敏感（平均估错一点，`f*` 差很多）；肥尾时真实最优更小。均值 ÷ 方差这个近似比精确的
  对数最优（直接求 `argmax mean(log(1 + rf + f × ex))`）偏高：独立核对里 QQQ 1.73 对 1.60、ONEQ 3.90 对 3.44，高 8–13%。

### 2.8 路径体验（path）

**`p_dd30_5y`、`p_dd50_5y`、`p_dd30_10y`、`p_dd50_10y` 5 / 10 年内遇到深回撤的概率**
- 方法：用输入频率的收益做平稳块重抽样（平均块长 `block_months` 个月，日数据就是 252 期），每条路径 10 年、从 1.0 起，
  算最大回撤；5 年的数用同一条路径的前 5 年（所以 5 年的概率不会高于 10 年）。“超过 30%”指回撤严格深于 −30%。
  单位 `prob`。
- 白话：随便挑一段 5 年 / 10 年来过，期间至少碰到一次跌三成 / 跌五成的概率。
- 怎么看：比历史上那一次最大回撤更全面；例如 10 年内跌五成的概率 60%，就要做好“大概率会遇到”的心理准备。
- 注意：只是把历史打散重组，不会出现历史里没有过的更大崩盘；数据不到 10 年时会反复用同一段历史（表里注明）；
  块越长越保留熊市的连续性，概率越高；月数据看不到月内回撤。

**`dd10_count`、`recovery_years_median`、`recovery_years_max`、`underwater_now_years` 回本时间**
- 定义：深度超过 10% 的回撤段数；其中已回本的那些段**从前高到回本**的时间（同 `max_dd_duration_years` 口径）的中位数和
  最大值；数据结束时还没回本的那段从前高到数据末尾已经多久（在新高就是 0）。单位 `count` / `years`。
- 白话：一次像样的回撤（跌一成以上）通常要几年回本，最慢的一次几年，现在是不是还套着。
- 注意：段数少时中位数没什么代表性；还没回本的段不进中位数和最大值（单独看 `underwater_now_years`）。

**`contrib_invested_usd`、`contrib_terminal_usd`、`contrib_max_dd_usd`、`contrib_max_dd_pct`、`lump_max_dd_usd` 每月定投 300 美元的影响**
- 定义：期初 10,000 美元，每个自然月最后一期收益之后存入 300 美元（最后一个月不存，所以总本金
  `= 10000 + 300 × (月数 − 1)`）。账户路径记录起点、每期收益之后的值、每次存入之后的值（所以存钱后马上下跌，
  是从存入后的金额算起）。`contrib_max_dd_usd = max(前高 − 当前值)`（美元），`contrib_max_dd_pct = min(当前值 / 前高 − 1)`；
  `lump_max_dd_usd` 是不定投、只放 1 万美元时的美元最大回撤。金额可用 `start_capital`、`contribution` 改。
- 白话：每月存钱买入时，账户上看到的最大亏损是多少美元、多少百分比，和一次性投入比怎样。
- 怎么看：定投让美元损失变大（因为钱更多了），百分比回撤往往变小（新钱在低位买入）；
  如果你是“看到少了几万美元就受不了”的人，看美元那一行。
- 注意：不计存入时的交易成本；美元数和回测长度强相关（越往后账户越大，同样的跌幅美元越多）。

### 2.9 可操作性（practicality）

**`turnover_one_way_per_year` 单边换手率**
- 公式：`Σ |traded| / 2 / 年数`（`traded` = 每笔成交金额 ÷ 当时账户价值，年数 = 收益期数 ÷ P）。单位 `frac/yr`，交易记录。
- 白话：一年里买卖的总金额，除以 2，再除以账户规模；1 = 一年把整个仓位换一遍。
- 怎么看：换手越高，成本、短期资本利得税、执行误差越大。

**`trades_per_year` 每年下单数**
- 公式：交易记录行数 ÷ 年数。单位 `count/yr`。
- 白话：每年要下几笔单。

**`cost_drag_per_year` 成本拖累**
- 公式：`Σ cost / 年数`（`cost` = 每笔佣金加买卖价差 ÷ 当时账户价值；与 `quant/evaluation/nav.py` 的同名指标同义）。
  单位 `frac/yr`。
- 白话：交易成本每年吃掉账户的百分之几。
- 注意：成本模型见 `docs/cost_model_ibkr_tiered.md`；小账户的最低佣金占比更高。

**`min_account_usd` 最小账户规模**（`meta`）
- 白话：能照规则执行（整股取整误差不大、最低佣金不吃掉太多）所需的最少本金。研究者按成本模型估计后填写。

**`permissions` 需要的账户权限**（`meta`）
- 取值：`margin`（保证金借钱）、`short`（做空）、`options`、`futures`、`leveraged_etf`、`inverse_etf`、`crypto` 的组合；
  `none` 是普通现金账户。
- 白话：开什么权限才能做；权限越多，出错和亏损的方式越多。

**`operational_complexity` 操作复杂度（1–5）**
- 规则：`1` 加上以下每条各 1 分，最高 5：每年超过 12 笔；每年超过 52 笔；同时持仓超过 10 只（`meta["positions"]`）；
  需要任何特殊权限；对执行时点敏感（`meta["timing_sensitive"]`：盘中下单、挂限价单、固定时刻下单）。交易次数未知时为空。
- 白话：1＝买了放着；5＝交易频繁、持仓多、要特殊权限、还要盯时点。
- 怎么看：实盘执行的出错概率随它上升；同样收益，越简单越好。

**`margin_call_drop` 追加保证金的跌幅门槛**（`meta`）
- 公式：`L` = 总持仓 ÷ 净值（`meta["margin_leverage"]`），`m` = 维持保证金比例（默认 0.25）。持仓一次跌 `d` 后，
  净值 ÷ 持仓 = `(1 − L d) / (L (1 − d))`，降到 `m` 时 `d* = (1 − m L) / (L (1 − m))`；
  `L = 2`、`m = 25%` 时 `d* = 1/3`（测试锁定）。不用保证金时为空。单位 `frac`。
- 白话：保证金账户里，持仓一次跌多少就会被要求追加保证金或强制卖出。
- 怎么看：和最差一天、最差一个月比：历史上真出现过比 `d*` 更大的单次下跌，那段历史在真实账户里会被强平。
- 注意：杠杆 ETF 不会追保，但 k 倍日杠杆 ETF 在标的单日跌 1/k 时几乎归零，而且有日度复利损耗；
  券商对波动大的股票和杠杆 ETF 要求的维持保证金可能远高于 25%，请按实际填写。

**`data_dependence` 数据依赖**（`meta`）
- 白话：每期算信号需要哪些数据：只要日收盘价，还是要财报、指数成分、付费数据。依赖越多，实盘越容易因为数据断供或修订出问题。

### 2.10 统计可信度（confidence）

**`t_vs_oneq`、`p_vs_oneq` 月度超额的 t 值和 p 值**
- 公式：`x_t = m_t − b_t`，`t = mean(x) / sd(x) × √n`（`metrics.t_and_ir`）；单边 p = Student t 上尾概率，
  自由度 `n − 1`（`stats.t_sf`）。单位 `t` / `prob`，月。
- 白话：超额收益是真的，还是运气？t 越大越不像运气；p 是“其实没有超额、却碰巧看到这么好”的概率。
- 怎么看：本项目 A 标准要求 t ≥ 2.0；试了很多版本时要用更高的门槛（Bonferroni，`criteria.bonferroni_t`）或看打折夏普。
- 注意：假设各月超额互相独立。策略和 ONEQ 完全相同（超额全是 0）时，按 `t_and_ir` 的约定 t 和 IR 记为 0、p 为 0.5，而不是空。

**`excess_cagr_ci_lo`、`excess_cagr_ci_hi`、`excess_cagr_boot_share_positive` 超额收益的重抽样区间**
- 方法：把共同月份的（策略月收益, ONEQ 月收益）成对做平稳块重抽样（平均块长 `block_months`），每次算两者月度复利 CAGR 之差，
  取第 2.5、97.5 百分位（95% 区间），以及差大于 0 的比例。单位 `frac/yr` / `prob`。
- 白话：考虑到“历史只是一种可能”，每年超额收益大概在什么范围。
- 怎么看：区间跨过 0，就不能说跑赢了 ONEQ。
- 注意：它不是未来的预测区间；第 1 类的点估计在日数据时用日复利，区间用月复利，两者略有差别。

**`years_of_data`、`years_vs_oneq` 数据年数**
- 定义：策略收益期数 ÷ P；与 ONEQ 共同的期数 ÷ 共同频率的 P。单位 `years`。
- 白话：结论是建立在几年数据上的。少于 10 年、没经历过一次完整熊市的结论要打折。

**`n_trials` 试验次数**（`meta`）
- 白话：选出这个策略之前一共试了多少个版本（参数组合、规则变体，包括失败的）。试得越多，最好那个越可能只是运气好。
- 怎么看：和 `deflated_sharpe`、Bonferroni 门槛一起看。

**`oos_status` 样本外状态**（`meta`）
- 取值：`passed`（在没参与挑选的数据或前瞻观察里通过）、`failed`（没通过）、`none`（还没做）。
- 白话：在“没见过的数据”上还灵不灵。样本内再好，`none` 也只是假设。

---

## 3. 建议的读法

1. **先看统计可信度**：t、区间、试验次数、样本外。如果这里站不住，后面的数字都只是“历史上碰巧这样”。
2. **再看能不能拿得住**：回撤之痛、尾部、路径体验（5 / 10 年内跌五成的概率、回本时间、定投时的美元回撤）。
3. **然后看收益和风险调整后收益**：CAGR、超额、夏普、卡玛、CRRA。
4. **最后看能不能做**：权限、复杂度、成本、强平门槛、数据依赖。
5. 用 `compare` 把策略和 ONEQ 本身放在一起看，每一行都和基准比，而不是看绝对数。

## 4. 通用注意事项

- 所有数字都来自回测：没有扣税，成本是模型估计，数据可能有幸存者偏差（见各研究台账的数据说明）。
- 回测期不同的策略不可直接比，尤其是最大回撤、卡玛、危机表现。
- 日数据和月数据算出来的回撤、夏普、CRRA 会有差别；表里 `freq` 列写明了用的是什么。
- 重抽样只重组历史，假设“未来像过去打散重排”；它低估了历史上没出现过的风险。
- 记分卡不是通过标准（第 0 节）。

### 6.10 小结和读法

- **收益好、其它角度差**：M3（收益第一，但最差一月 −29%、现在还在 −37% 的回撤里、换手 379%/年、样本外没过）；
  LEV-B3（收益第四，但回撤痛苦、和大盘关系都排最后，下跌捕获 1.41，全历史 −87%、水下 15 年，对恒定 1.37 倍没有显著超额）；
  M1 / M2 / M6（最大回撤比 ONEQ 深 6–9 个百分点，2022 年多亏 6–8 个百分点，样本外没过）；V3（和 LEV-B3 类似但轻一些）。
- **收益一般、其它角度好**：T01、SEL-A/P（回撤、尾部、和大盘关系都排在前面，长窗口和 1999–2013 窗口里 T01 是第一；
  但跑输 ONEQ，样本外 / 滚动选参都没过）。
- **比较均衡**：S-MISP（稳定性第一、回撤和尾部都不差，但可操作性最差、t 2.23 低于它自己的 Bonferroni 门槛 3.0）；
  BT4b（风险调整、效用都排前面，但只有 12 年数据，赶上了比特币最好的十年，要开加密货币权限）。
- **看起来最好但比较无效**：S3-Yb（幸存者偏差；对 H_match 只多 0.1 个百分点）。
- 读的顺序：先看统计可信度和 6.7 的公平对照组，再看自己能不能拿得住（回撤、尾部、6.4 的全历史），最后才看收益。
  所有候选都是看过历史才选出来的，前瞻观察（`docs/forward_observation_checklist.md`）才是真正的检验。
