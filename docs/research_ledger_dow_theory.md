**规则（记号）**
每个指数各自独立地识别波段高点 / 低点（只用到当天收盘为止的数据）：
- 处在"上升段"时记录段内最高收盘 H；当从 H 开始的回落满足"确认条件"时，H 被**确认**为波段高点（确认发生在满足条件的那一天，不回填），
  转为"下降段"，从 H 之后的最低收盘开始记录。下降段对称。
- 确认条件（族不同）：
  - 回落幅度 ≥ p（从 H 到 H 之后的最低收盘）；
  - R 族另外要求：从 H 起已经过了至少 D 个交易日（"次级折返持续 3 周到 3 个月"取下限，15 个交易日 ≈ 3 周），并且回落 ≥ 前一段涨幅的 1/3
    （"次级折返回吐前一段主要涨幅的 1/3 到 2/3"取下限）。上限（3 个月、2/3）不作为过滤条件，因为它们描述的是典型情形，不是识别规则。
- 单个指数的"突破方向"：收盘价高于最近一个已确认的波段高点 → "向上"；低于最近一个已确认的波段低点 → "向下"；否则不变。
  P 族（严格形态）另外要求：向上突破时，最近一个波段低点要高于前一个波段低点（低点抬高）；向下突破时，最近一个波段高点要低于前一个（高点降低）。
- **市场主要趋势（相互确认）**：两个指数的突破方向都变成"向上" → 牛市；都变成"向下" → 熊市；只有一个变了（"未获确认"）→ 维持原趋势。
  确认没有时间限制（经典读法）。
- 交易：牛市 = 100% QQQ；熊市 = 100% 短期国债 ETF（RF − 0.10%/年）。信号在决策日 t 收盘后判定，**t 的下一个交易日收盘**成交。

### 第一版运行后发现的定义错误（2026-10-03，修正前写下）

第一版跑完后，R 族 5 个配置的最大回撤都在 −78% 到 −82%，几乎和 QQQ 买入持有一样，于是逐条检查波段点，发现第 0 节"回落 ≥ 前一段涨幅的 1/3"
被实现成"前一段 = 从最近一个**已确认的 R 族波段低点**到当前高点"。这在长牛市里会自我锁死：一次折返不满足 1/3，就不算波段，"前一段"继续变长，
下一次折返更难满足。实际数据里，DJI 从 1992 年的低点 3,675 起，直到 2001-09-17 才确认第一个波段高点；1998 年 7–10 月下跌 19%、持续 3 个月
（教科书式的次级折返）因为只回吐了 1992 年以来涨幅的 1/4 而不被承认。这不是雷亚 / 哈密尔顿的意思（他们说的是"上一次次级折返以来"的涨幅），
所以判定为定义错误。第一版 5 个 R 配置的结果照样保留、计入试验次数（见下表）。

**第二版 R 族的定义（只改这一处）**：另外用"幅度 ≥ p 且持续 ≥ D 天"（不看回吐）识别一层"中级波段点"；1/3 回吐的参照段 = 从当前高点之前最近的
一个波段低点（中级波段低点或 R 族自己的波段低点，取较近的那个）到当前高点。下降段对称。其他（p、D、确认、交易）完全不变。
冻结的仍是 `R_p5_D15`，用第二版定义——这是在看到第二版任何结果之前写下的；不管第二版结果好坏都不再改。

**多重检验门槛**：18 次试验，单侧 5% Bonferroni 门槛 t = 2.77；deflated Sharpe 要 ≥ 0.95。

## 开发期结论（1999-03-10 至 2014-12-31，约 15.8 年）

参照：QQQ 买入持有 CAGR +5.1%，最大回撤 −83.0%，卡玛 0.06。1993-01 至 1999-03（NDX 价格）：买入持有 CAGR +32.4%，最大回撤 −23.0%。

- **整体：没有一条显著。** 18 个配置中月度超额 t 值最高的是 `P_p5`（1.53，DSR 0.43），离门槛 2.77 / 0.95 很远；18 个中 13 个年化跑输 QQQ。
- **参数之间极不稳定，排名基本是运气。** `P_p5` 开发期最好（CAGR +16.8%、回撤 −17%），但它两侧的 `P_p3`（+2.1%、−80%）和 `P_p8`（−0.8%、−83%）
  都很差；`R_p8_D15`、`Z_p8` 也好，但 `R_p3_D15`、`Z_p3` 很差。原因是道氏信号很少（每年 0.4–3 次），成败取决于 2000–2002、2008 两次熊市里
  某一两个信号恰好落在哪一天，差几天就是几十个百分点。
- **结构性问题：信号看的是道琼斯工业 + 运输（老经济蓝筹），交易的是纳斯达克 100。** 2000–2002 年纳斯达克崩盘时，道指和运输指数相对坚挺，
  多数规则在 2000 年末或 2001 年初给出"牛市"信号，随后 QQQ 在 2001 年再跌 30–50%（`R_p5_D15` 2001 年 −49.8%，比 QQQ 的 −33.3% 更糟）。
- **2008 年确实有用**：几乎所有规则都在 2007-11-21 转熊，2008 年少亏 25–45 个百分点。但 2009 年反弹多数踏空（`R_p5_D15` 2009 年 +7.6%，QQQ +54.7%）。
- **1993–1999 段（长牛市）**：多数规则持平或跑输，`R_p5_D15` 每年少 7.0%，因为 1998 年 8 月转熊、12 月才转回。
- **相互确认确实比只看一个指数好**：只看 DJI 或只看 DJT（N 族）年化少 3%、回撤 −71% 到 −80%，都比同参数的两指数确认版 `Z_p5` 差。
- **第一版 R 族（R1）**因定义错误基本不产生信号（现金时间 14–25%），回撤 −78% 到 −82%，结果保留在表中。
- 成本可以忽略（每年 0.01%–0.13%）；改为当日收盘成交或现金不计利息，超额变化都在 ±1.5% 以内。
- 用一次性检验的三条标准"预演"开发期（只供参考）：18 个中 6 个三条全满足（`Z_p8`、`R_p5_D15`、`R_p8_D15`、`R_p5_D10`、`R_p5_D20`、`P_p5`），
  这主要是因为开发期 QQQ 本身回撤 −83%，标准很容易满足；近十年 QQQ 回撤小得多，标准会难得多。

## 冻结给一次性检验（2015-01 以后）的规则：`R_p5_D15`（第二版定义）

选它的理由在第 0 节跑之前就写下了：它是雷亚 / 哈密尔顿经典读法最直接的翻译，参数在范围中间或文献给出的下限。**不是**开发期最好的
（开发期 `P_p5`、`R_p8_D15`、`Z_p8` 好得多，但它们的邻居很差，挑它们就是挑运气）。`R_p5_D15` 在开发期表现平平（CAGR +4.7% 对 QQQ +5.1%，
回撤 −60% 对 −83%），照样冻结。

- 每个交易日收盘后，分别对 ^DJI、^DJT 收盘价识别波段：从段内极值回撤 ≥ 5%、距极值 ≥ 15 个交易日、且回撤 ≥ 前一段（自最近一个中级或 R 族波段点起）
  幅度的 1/3 时，确认该极值为波段点（确认日 = 满足条件那天）。收盘高于最近确认的波段高点 → 该指数"向上"；低于最近确认的波段低点 → "向下"。
  两个指数都"向上" → 牛市；都"向下" → 熊市；否则维持。状态从 1992-01-02 连续算下来（2014-12-30 收盘的状态决定入场时持仓）。
- 牛市 = 100% QQQ；熊市 = 100% 短期国债 ETF。状态改变后**下一个交易日收盘**成交。成本与 QQQ 台账第 0 节相同；基准 = QQQ 买入持有（同样成本口径）。
