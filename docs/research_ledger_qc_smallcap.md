# 中小盘教科书策略（神奇公式 / Piotroski F 分 / 小盘动量）在 QuantConnect 上的检验：研究台账

> 代码：`qc/magic_formula/main.py`（S1）、`qc/piotroski/main.py`（S2）、`qc/smallcap_momentum/main.py`（S3）。
> 平台：QuantConnect 云端回测（免费账户），用它自带的 Morningstar 时点基本面数据和复权日线（含已退市股票，没有幸存者偏差）。
> 账户：IBKR Pro，1 万美元，现金账户，只做多，不考虑税。

## 0. 事先登记（2026-10-05，在任何一次运行之前写下）

### 0.1 为什么做这一组

大中盘上试过的东西全部没能跑赢 ONEQ（见 `docs/research_ledger_*.md`、`docs/audit_stock_studies.md`）。
学术上"价值 / 质量 / 动量"类异象在小一些、关注度低一些的股票里更强，所以这一组只换方向：
**市值较小的股票，用教科书原文的参数，不调参，每个策略只跑一次。**

### 0.2 基准和判定区间

- **判定基准 = ONEQ**（纳斯达克综合指数 ETF），用 QuantConnect 的复权收盘价（复权 = 拆股和分红都算进去，相当于总收益）。
- QQQ 一并记录，不用于判定。
- 回测区间 2014-01-01 至 2026-08-31。判定分两半：**前半 2014–2019**，**后半 2020-01 至 2026-08**；全期 2014-01 至 2026-08 用于 t 值。

### 0.3 三个策略共用的设定

- **股票池（每天按当天已知的数据筛，退市股保留）**：
  - 普通股：`f.security_reference.security_type == "ST00000001"`，且 `f.security_reference.is_depositary_receipt` 为假（排除 ADR，即外国公司在美上市的存托凭证）；
  - 公司注册国 `f.company_reference.country_id == "USA"`；
  - 主上市交易所 `f.security_reference.exchange_id` 属于 `NYS`（纽交所）、`NAS`（纳斯达克）、`ASE`（美交所）；
  - `f.has_fundamental_data` 为真，股价 `f.price >= 5` 美元，日成交额 `f.dollar_volume >= 100 万` 美元；
  - 市值 `f.market_cap` 按各策略的区间；行业排除（Morningstar 行业代码 `f.asset_classification.morningstar_sector_code`：103 = 金融，207 = 公用事业）按各策略原文。
- **执行**：日线；调仓日前一个收盘出信号，订单用**收盘市价单**（market-on-close，MOC），第二个收盘成交，和 `qc/donchian20_wide/main.py` 相同。
  - 先卖：不在新名单里的持仓全部卖出；
  - 卖单成交、现金结算后再买（现金账户卖出的钱要结算后才能用），买单最多连续尝试 10 个交易日；
  - 每只新股买入金额 = 当时总资产 / 10，不超过已结算现金的 98%，只买整股；
  - 留在新名单里的老持仓不调整股数（不为"恢复等权"额外交易）；
  - 等权、最多 10 只；名单不够 10 只或买不进时，剩下的钱放现金（0 利息）。
- **成本**：QuantConnect 的 IBKR 佣金模型、现金账户；QuantConnect 默认不加滑点。小盘股买卖价差比大盘宽，这一项没计入，**结果对策略偏乐观**，判定时要记住。
- **记录**：每天记下策略净值、ONEQ、QQQ 收盘；回测结束写"运行时统计"（runtime statistics），格式与 donchian 文件相同：
  - `2014-2019 strat/ONEQ/QQQ/MDD`、`2020-2026 …`、`2014-2026 …`：三者的年化收益（CAGR）和策略最大回撤（MDD，从高点到低点的最大跌幅）；
  - 另加 `… MDD ONEQ/QQQ`：同一区间 ONEQ 和 QQQ 的最大回撤（判定 B 需要）；
  - `Y<年份> strat/ONEQ/QQQ`：每年收益；
  - `M<年份> strat:ONEQ %`：该年每个月的策略和 ONEQ 月收益（百分比，两位小数，空格分隔），2014-01 至 2026-08 共 152 个月；
  - `<区间> monthly excess mean/t/n`：月超额收益（策略月收益 − ONEQ 月收益）的均值、t 值、月数，分前半、后半、全期。
  - 和 donchian 文件的一处小差别：每个区间 / 每年的起点用"区间开始前最后一个收盘"做基数（donchian 用区间内第一个收盘），少丢一天收益。
- 日志尽量少（免费账户限制日志量），代码里没有逐笔日志。

### 0.4 三个规则（全部是教科书参数，没有调过）

**S1 神奇公式（Greenblatt《股市稳赚》）**
- 市值 ≥ 3 亿美元，无上限；排除金融（103）、公用事业（207），以及 REIT（`f.company_reference.is_reit`，书写成时 REIT 属于金融板块）。
- 盈利收益率 = EBIT / 企业价值（EBIT = 息税前利润，`f.financial_statements.income_statement.ebit.twelve_months`；
  企业价值 = 市值 + 债务 − 现金，`f.company_profile.enterprise_value`）。
- 资本回报率 = EBIT / (净营运资本 + 净固定资产)。净营运资本 = `balance_sheet.working_capital`，缺失时用流动资产 − 流动负债；
  净固定资产 = `balance_sheet.net_ppe`，缺失按 0。资产负债表取最新一期（`three_months`，没有再用 `twelve_months`）。
- 企业价值 ≤ 0 或资本 ≤ 0 的剔除。两项各自排名（最好 = 1），名次相加，取和最小的 10 只（并列时盈利收益率高的优先）。
- 每季度调仓：1、4、7、10 月的第一个交易日。
- 和书的差别：书里建议持有 20–30 只、每只持有一年；这里按登记要求用 10 只、每季度调仓。净营运资本没有扣除"多余现金"（书里有这一步，数据没有现成字段）。

**S2 Piotroski F 分价值股（Piotroski 2000）**
- 市值 3 亿–50 亿美元；排除金融（103）（银行没有流动比率、毛利率，F 分算不出来）。原文不排除公用事业，这里也不排除。
- 账面市值比 = 1 / 市净率（`f.valuation_ratios.pb_ratio`，> 0 才算），取最高的 20%（最便宜的五分之一）。
- F 分（9 个信号，每个成立得 1 分），全部用年报数（`twelve_months`）。t = 调仓日已知的最近一个财年；t−1、t−2 = 365 天前、730 天前已知的最近财年
  （用 `self.history[Fundamental](symbol, 开始, 结束)` 取当时的基本面快照，取 14 天窗口里的最后一个），三个财年的结束日（`financial_statements.period_ending_date.twelve_months`）
  两两必须相隔 300–430 天，否则这只股票跳过：
  1. ROA > 0（ROA = 持续经营净利润 / 年初总资产；持续经营净利润 `income_statement.net_income_continuous_operations`，缺失时用 `net_income`）；
  2. 经营现金流 CFO > 0（`cash_flow_statement.operating_cash_flow`）；
  3. ROA 比上一年高；
  4. CFO / 年初总资产 > ROA（应计项：利润有现金支撑）；
  5. 长期债务 / 平均总资产比上一年低（`balance_sheet.long_term_debt`，缺失按 0；没有债务两年都是 0 时不得分）；
  6. 流动比率（流动资产 / 流动负债）比上一年高；
  7. 这一年没有发行普通股（`cash_flow_statement.common_stock_issuance` ≤ 0 或缺失）；
  8. 毛利率（`gross_profit / total_revenue`）比上一年高；
  9. 资产周转率（营收 / 年初总资产）比上一年高。
- F ≥ 8 的股票，按 F 从高到低、再按账面市值比从高到低，最多取 10 只；不够 10 只就少持，剩下的钱放现金。
- 每年 5 月第一个交易日调仓（原文在财年结束后第 5 个月建仓，12 月年结的公司就是 5 月），持有一年。
- 2014-01 至 2014-04 还没到第一次调仓，全部是现金（这几个月照样算进前半的收益）。
- 实现上的注意：信号 1、2、4、7 只用今年的数（年初总资产 > 0 时，ROA > 0 等价于净利润 > 0，信号 4 等价于 CFO > 净利润），
  这 4 个里错 2 个以上的股票不可能 F ≥ 8，直接跳过，不去取历史快照（只为省运行时间，不改变结果）。

**S3 小盘动量（Jegadeesh-Titman 12-1 月动量）**
- 市值 3 亿–30 亿美元；不排除任何行业（原文用全部股票）。
- 动量 = 调仓前最后一个收盘往回第 21 个交易日的收盘 / 往回第 252 个交易日的收盘 − 1（即过去 12 个月、跳过最近 1 个月），用复权日线
  （`self.history(symbols, 253, Resolution.DAILY)`），历史不满 253 天的股票跳过。
- 取动量最高的 10 只；每月第一个交易日调仓；调仓日股价 < 5 美元的不选（股票池已过滤）。

### 0.6 试验次数

- 本组：**3 次**（S1、S2、S3 各 1 次），0 个校准变体。
- 之前的研究（累计，用的是同一时期或重叠时期的美股，所以这 3 次不是"干净"的第一次）：技术指标 56 次登记 + 1268 个事后网格点；
  CAN SLIM 232 个变体；Livermore 118；反转 148；O'Neil 26；OSAP 212 个因子筛查 + 4 次运行；QQQ 择时 142；道氏理论 18；
  QuantConnect O10 宽股票池 1 次；另有 2012–2019 / 2020–2026 / SUE 台账的试验。登记过的合计至少约 750 次。
- 仅按本组 3 次算，单侧 5% 的 Bonferroni 门槛（多重检验校正：试得越多，门槛越高）是 t ≈ 2.13；按全部历史试验算会高得多（> 3.5）。
  下面的判定标准仍用 t ≥ 2（与以前台账一致），但结果里会同时写明是否过 2.13。

### 0.7 通过标准（对 ONEQ，前半 2014–2019、后半 2020-01..2026-08 分开判）

满足 A 或 B 即算通过：

- **A（收益更高）**：前半、后半两段的年化收益都高于 ONEQ，**且**全期（2014-01..2026-08，152 个月）月超额收益的 t ≥ 2。
- **B（回撤小很多、收益不太差）**：前半、后半两段，策略最大回撤都比 ONEQ 浅至少 10 个百分点（例如 ONEQ −30%，策略要好于 −20%），
  **且**每段的年化收益落后 ONEQ 不超过 3 个百分点。

t 值的算法（运行时统计里直接给出，也可以用 `M<年份>` 那 13 行的 152 个月收益自己复算）：
月超额 = 策略月收益 − ONEQ 月收益（月收益 = 月末收盘净值 / 上月末 − 1；2014-01 的基数是第一个记录的收盘，2014-01-02）；
t = 均值 / (样本标准差 / √n)，样本标准差用 n − 1 做分母，n = 152。
年化收益、最大回撤直接读 `2014-2019 …`、`2020-2026 …` 两行；ONEQ 的最大回撤读 `… MDD ONEQ/QQQ` 行。

### 0.8 已知的不确定之处（运行前写下）

- `twelve_months` 的含义：LEAN 源码里利润表、现金流量表、资产负债表的字段都有 `three_months` / `twelve_months` 等周期；
  这里假设 `twelve_months` 是最近一个 12 个月报告期（年报）。如果某些公司它实际是滚动 12 个月（TTM），S1 不受影响（书里本来就用 TTM），
  S2 的"财年结束日相隔 300–430 天"检查会过滤掉不一致的情况。
- Morningstar 的比率类字段（如 `pb_ratio`）按产生它的申报日记时间（比报告期末晚约 2 个月），是时点数据，没有前视；
  `enterprise_value` 属于 `company_profile`，是每天更新的值。
- `common_stock_issuance` 可能把员工期权行权的小额发股也算进去，会让 S2 的信号 7 比原文更严格。
- 现金账户的结算天数由 QuantConnect 模型决定；买单 10 个交易日的重试窗口是为了等结算，不是参数。
- 小盘股价差、冲击成本没有计入（见 0.3）。
