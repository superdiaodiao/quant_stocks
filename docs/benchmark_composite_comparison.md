## 先说结论（大白话）

1. **换基准是看过结果之后才做的，这本身就是一个更弱的检验。** 先看到"输给 QQQ"再换一个更容易赢的尺子，等于多给了自己一次机会。
   所以下面的数字只能当"参考信息"，**原来事先写定的判定（全部未通过）不变**。
2. **只有一次性检验的结果算证据**：QQQ 200 日线规则、道氏理论规则、利弗莫尔 #20 的两段检验。CAN SLIM #215 和反转 rev-ind-v1
   只有开发期（样本内、挑过参数）的数字，**从来没有被检验过**，再好看也不算证据。
3. 这 12 年里 **QQQ（纳斯达克 100）每年比综合指数多赚约 2 个点**（2015–2026：QQQ 年化 19.1%，综合指数总收益 17.0%）。
   所以换成综合指数后，所有策略的"超额"都会好看 1.5–2.5 个点——这不是策略变好了，是尺子变短了。而且择时规则和反转策略本身持有的就是 QQQ，
   它们"赢综合指数"的那部分，有一块其实是"QQQ 赢综合指数"。
4. **换了基准后，三个一次性检验仍然全部跑输综合指数**：
   - QQQ 200 日线规则：年化 14.5% 对综合指数 17.0%，**落后 2.5 个点/年**（对 QQQ 落后 4.6 个点）；最大回撤 −25% 对 −35%。
     按原来的三条标准重算：回撤浅 9.9 个点（要 ≥ 10，差 0.1 个点不过）、卡玛比率更高（过）、年化落后 ≤ 3 个点（过）——**三条过两条，仍不通过**。
     月度超额 t = −0.79（不显著）。这是最接近的一个，但"差一点"仍是不通过；而且是换尺子之后才"接近"的。
   - 道氏理论 R_p5_D15：年化 12.6% 对 17.0%，**落后 4.5 个点/年**；回撤 −23% 对 −35%。三条过两条（年化落后超过 3 个点），仍不通过。t = −1.12。
   - 利弗莫尔 #20：检验 1（2023-01 至 2026-08）年化 22.7% 对 30.0%，**落后 7.3 个点**；检验 2（2014–2016）−0.6% 对 10.0%，**落后 10.6 个点**；
     合并 80 个月 t = −0.43；回撤两段都比综合指数**更深**（−27% 对 −24%，−25% 对 −18%）。不通过。
5. 两个只在开发期的结果（**未检验，不算证据**）：
   - CAN SLIM #215（2017–2022）：年化 14.3% 对综合指数 12.7%，**超额 +1.6 个点**（对 QQQ 是 −0.8），月度 t = 0.54，远不显著；回撤 −37% 比综合指数 −35% 还深。
     这是 232 个变体里事后挑出来的，换基准后"变正"没有意义。
   - 反转 rev-ind-v1（2012–2016）：年化 29.0% 对 16.6%，超额 +12.4 个点，t = 2.01。但它是 148 次试验里挑出来的，多重检验门槛 t = 3.40，
     换基准后 t 从 1.95 变成 2.01，仍远低于门槛；而且它 100% 持有 QQQ，超额里有约 0.9 个点/年是"QQQ 赢综合指数"。
6. 两种综合指数算法几乎一样：ONEQ（扣 0.21% 费用）比 "^IXIC + 估算股息" 每年低约 0.2–0.4 个点，结论完全不受影响。

**一句话：换成综合指数，差距缩小了，但没有一个一次性检验的规则跑赢它；唯二"跑赢"的是没检验过的开发期结果，不能算数。**

## 基准是怎么算的

| 名称 | 来源 | 说明 |
|---|---|---|
| **ONEQ**（主基准） | Yahoo 日线复权收盘价（adjusted close），2003-10-01 起 | Fidelity 纳斯达克综合指数 ETF。复权价包含股息再投资，已扣约 0.21%/年费用，所以略低于指数本身 |
| **^IXIC + 股息估算**（交叉核对） | Yahoo ^IXIC 日收盘（价格指数，不含股息）+ 估算股息率 | 股息率来源：**ONEQ 当年实际派息（Yahoo 分红记录）÷ ONEQ 当年平均收盘价，再加回 0.21% 费用**（基金派息是扣费后的），平均摊到当年每个交易日。2012–2026 每年约 0.6%–1.5%（2019 年 2.3%，ONEQ 那年派息偏高）。注意它的股息部分不是独立来源，只有价格部分独立 |
| **QQQ**（原基准，对照） | Yahoo 日线复权收盘价 | 和原研究用的 QQQ 核对过：月度收益最大差 0.0001%，各段年化差 < 0.03 个点 |

原始数据只放本机 `/Users/bytedance/code/quant_stocks/research_cache/benchmarks/`（`chart_ONEQ.json`、`chart_%5EIXIC.json`、`chart_QQQ.json`，2026-10-03 下载），不进 Git。

**口径**：每一项都用规则自己的起止日期（起点 = 规则净值的起始收盘，终点 = 最后一个净值日），基准在同一段上算。
年化 = 总增长 ^ (365.25 / 日历天数) − 1（所以和原台账按 252 个交易日算的年化可能差 0.0x 个点）。年化超额 = 规则年化 − 基准年化。
月度超额 t = 每月（规则收益 − ONEQ 收益）的均值 ÷ 标准差 × √月数。最大回撤：基准一律用日线；
QQQ 200 日线和道氏规则只保存了月度收益，回撤用原一次性检验 `results.json` 里存下的**日线**最大回撤；反转策略只有周度净值，回撤按周算
（同样按周算，ONEQ −17.8%、QQQ −15.4%）。
