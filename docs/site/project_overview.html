能不能稳定跑赢纳斯达克？

目标是找到一个扣掉真实成本后，能长期跑赢纳斯达克综合指数（以 ONEQ 含分红为基准）的策略。项目只做研究和模拟，从不连接券商、从不下单。

最后更新：2026-10-11代码：superdiaodiao/quant_stocks数据备份：私有仓库 quant_stocks_data

到目前为止的结论

测过的方向里，没有一个能在不多冒风险的前提下稳定跑赢纳指。看起来跑赢的，都是靠加杠杆或更集中地押注巨头，换一段历史就失灵。只想跑赢纳斯达克综合指数，最简单的是持有 QQQ（长期每年多约 2 个点）。几个"差一点通过"的候选正在用以后的真实行情观察，不投钱。

研究怎么做 每一步的规矩都写在台账里

  1. 建数据多来源交叉核对，冻结成版本，以后不再改动
  2. 先登记规则和通过标准先写进台账，再算结果，不许看了结果改规则
  3. 回测检验历史分两段，一段挑参数、另一段检验，再反过来；按 IBKR 真实成本扣费
  4. 提高门槛试的组合越多，统计门槛越高，防止碰巧好看
  5. 前瞻观察差一点通过的放进观察，用以后的真实数据检验 2–3 年
  6. 才考虑投钱观察期满并达标，才可能实盘；目前没有

通过标准（和 ONEQ 比，两段都要满足其一）：A 收益更高，且月度超额收益的 t 值 ≥ 门槛（≥2，试得多时更高）；B 最大回撤浅 10 个点以上，且年化落后不超过 3 个点。

研究总表

类别方向结果要点

反复出现的规律

指数被巨头带着走

纳指按市值加权。选股策略持有的巨头不够多，在 2014 年以后"最大几家涨得最多"的行情里，结构上就会落后。

择时能少亏，但会踏空

均线、波动、大盘状态这些信号能躲开一部分下跌，但急跌后的反弹往往错过，扣成本后打不过一直持有。

跑赢的多是在冒更多风险

加杠杆、集中持有巨头、卖期权叠加，跑赢靠的是承担更多风险。比如集中巨头在 2014–2026 年通过，换到 1999–2013 年全部失败。
